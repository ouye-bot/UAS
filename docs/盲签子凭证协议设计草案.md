# 飞证 · 盲签子凭证协议设计草案（R4 演进·纯设计稿）

> 状态：**设计草案 v0.1（2026-10-06）——未实现、未评审、未立项**。本文只新增设计，
> 不改任何代码与既有文档。所有代码锚为撰写日快照（行号随演进漂移，以语义锚为准）。
> 纪律：诚实优先——哪些是成熟构造、哪些是开放问题，逐条标注（🟢成熟 / 🟡需专项
> 评审 / 🔴开放问题）。
>
> 术语白话（首现解释）：
> - **盲签名**：签名人（RA）给一份文件签字，但看不到文件内容，事后也无法把
>   "签过的那份"和"用户最终出示的签名"对上号（Chaum 1982）。
> - **拖库**：攻击者拿到机构数据库的完整副本（备份盘/SQL 注入/内部导出）。
> - **协同签名（两方签名）**：私钥拆成两半分持，双方各跑一段协议、谁也不接触
>   对方那一半，最后拼出一个完整有效的签名。
> - **秘密共享**：把一个数拆成两片随机数（加起来才等于原数），单片不泄露信息。
> - **伪名/空付器（nullifier）**：一个一次性"花掉凭据"的公开记号——能证明
>   "这是同一份匿名凭据在重复请求"，却推不出凭据属于谁（Zcash 同族机制）。
> - **组织级 TCB**：为了系统运转不得不信任某机构守护的数据边界（此处=RA 库）。

## 0. 一句话问题陈述

出示层与撤销层已做到不可链接，但**签发层（RA 仪式）是实名全知的**：RA 在签发
每张子凭证时看到 M_A′ 全文并全量入库，`sub_credentials` 表以 `credential_id`
外键直连实名主凭证——RA 拖库（或 RA 与授权服务合谋）= 该用户的**历史飞行授权
记录可整体重放回真人**。盲签的目标：RA 仍能执行"授权某注册者获得子凭证"这一
职能，但**看不到也推不出**该子凭证的内容与后续使用。

## 2. 目标与非目标

**目标**（G1..G5）：
- G1 签发盲化：RA 签发子凭证时看不到 M_A′ 任何槽位（id′、C、pk′、exp、par），
  签发记录不可与出示/授权记录重放对应；
- G2 职能不丢：RA 仍能拒绝"未注册/已吊销/配额超限"的申请（资格核对）；
- G3 电路零换代：AUTH 电路（19,434 约束、Z_A/pk_RA 常量锚、实例面）与链上 pin
  **零改动**——换电路=换代成本（B1 演进史 104,287→19,434 多代投入+全量回归）；
- G4 追责路径不破：固件事件→令状→双控→RA 解锁实名，全链保持；
- G5 撤销语义尽量保持：被吊销者的**未来签发**立即拒绝；已签发子凭证的残余
  有效期如实量化披露。

**非目标**（如实排除）：
- N1 不追求"撤销即时杀死已签发子凭证"与签发盲化同时成立（见 §5.4 有界窗）；
- N2 不防御 RA 签名私钥失陷（钥丢=可签任意凭证，任何盲签方案都无解，属 KMS/
  HSM 域——口径卡 C+3 KMS 演进线）；
- N3 不改主凭证注册流程（注册本来就是实名仪式，隐私让渡在此刻已发生）。

## 3. 核心设计裁决（三条，逐条论证）

### 3.1 裁决一：盲签的**输出必须是标准 SM2 (r,s) 签名于原 165B M_A′**

这是 G3 的直接推论。电路在电路内验 RA 签名，Z_A(pk_RA) 是装配期常量锚、烧进
pin（F9）。因此：
- 盲签产物若不是 (r,s)@M_A′，电路须换代（违反 G3）；
- 盲签所用钥若不是同一把 sk_RA（pk_RA 变），Z_A 锚漂移=电路重装配+pin 重发+
  链上公示更新+全量 e2e 回归（同为换代）。
**推论**：任何"换钥/换签名格式/换消息结构"的优雅方案（如把 RA 换成 PS/BBS
匿名凭证签发者）在本系统语境下都隐含一次电路换代。v1 全部设计围绕
"**同一把钥、同一份报文、标准签名输出**"展开。

### 3.2 裁决二：SM2 **原生代数盲签**路线——诚实排除（🔴开放问题，不押注）

把 SM2 验签恒等式展开：签发侧 `k = s + d·(r+s)`（s 为响应，d 为私钥），验证侧
`r = e + x([s]G + [(r+s)·P])`。与盲 Schnorr（响应 `s = k + c·d` 对挑战线性，
隐点 R′=αR+βG 有两个自由度可吸收盲化因子）对照，SM2 的隐点**被 (s, r+s) 唯一
确定、没有自由参数**，且 r=e+x₁ 把哈希与 x 坐标混在同一个域元素里——附录 A
给出两条最自然的盲化尝试（摘要缩放 γ·e、仿 Schnorr 挑战平移）的推演，均因
x 坐标非线性失败。文献现状（🟡）：
- 国内期刊/专利存在多篇"SM2 盲签名/两方协同盲签名"提案，但**无 GM/T/GB 国标**，
  多数提案缺少 blindness 与 one-more 不可伪造性的严格归一证明（盲签两大性质
  的形式化基准=Pointcheval–Stern 2000），个别族已被 ROS 型攻击覆盖；
- 直接采用未经证明的提案=把"隐私设计"建在未审计地基上，与 D18 纪律相悖。
**结论**：原生盲 SM2 列为 🔴开放问题（§7 立 P0 评审项），**v1 不押注**。

### 3.3 裁决三：v1 主攻路线=**消息隐藏的两方协同签名**（message-private co-signing）

🟡（构造部件成熟、协议组合需专项证明）。把"盲签"从代数技巧改写为安全两方计算
（2PC）问题：私钥拆份额——RA 服务域持 d₁、签发代理域持 d₂（d=d₁+d₂，或乘法
份额，按所选协议），M_A′ 与摘要 e=SM3(Z_A‖M_A′)**只存在于用户侧**；两方以
秘密共享输入跑协同签名，最终用户独得完整 (r,s)。要点：

- **先例**：ECDSA 域 Lindell（CCS 2017）两方签名协议是业界钱包实践基础，其
  消息本就不经过签名人——天然服务本场景；SM2 域两方签名有多篇公开文献
  （Tan et al. 2023 多方协同；基于乘法转加法 M2A 的实用两方 SM2 签名），
  GmSSL 等开源栈有协同签名实践。SM2 协同签名**无国标盲签形态**，把 e 从
  公开输入改为共享输入属局部改造，安全证明义务见 §7-O1（诚实标注）。
- **钥迁移**：现行 KMS 内 sk_RA 为单钥（进程内持有）。迁移=一次性份额仪式：
  d₁ 注入 RA 域、d₂ 注入签发代理域、原钥销毁；pk_RA 不变 ⟹ 电路/链面零影响。
  仪式与口径卡 C+3 的钥注册表/轮换纪律同族。
- **为什么"签发代理"不重新引入全知方**：代理只见秘密共享片段（d₂ 与掩码值），
  见不到 d 全量也见不到 M_A′；其与 RA 合谋才等价于现状——合谋面**从
  "RA 单方全知"收窄为"RA×代理×用户材料三方中至少两方合谋"**，与"RA 与授权
  服务分权"同构（E2 既有边界表述的自然延伸）。

## 4. 资格核对悖论（六问之一）

### 4.1 悖论陈述

盲签后 RA 看不到 M_A′，则 F2 的原像知识认证（重算 C）失效——RA 凭什么相信
"申请人已注册、未吊销、配额未超"？同时**不能让用户把 C/handle 亮给 RA**（C 与
handle 在 RA 库内唯一对应实名主凭证，一亮=链接回真人）。

### 4.2 三候选机制对比与选型

| 候选 | 机制 | 优点 | 致命伤/代价 | 判定 |
|---|---|---|---|---|
| A 预签发额度池 | 注册（实名时刻）一次盲发 20 张"空白签名" | 零新电路 | M_A′ 含 24h TTL 的 exp_u，注册时刻无法预知 ⟹ 预签出的签名签不出合法 exp；改为签"提货券"则兑付时 RA 见券=链接 | 排除 |
| B 纯伪名线程 | 用户亮 N=H(导出量) 计数配额，RA 明面判重 | 极简 | N 与 C 的绑定无密码学保证（可伪称任意 N 绕配额），或绑定可逆推 C | 仅作 C 的组件 |
| C **ZK 资格证明+纪元伪名** | 用户在零知识下证明资格五条，同时亮伪名 N 供 RA 计数 | 职能完整保留、链接面量化可控 | 需新增 ISSUANCE 证明电路（构件全部现成） | **选定** |

### 4.3 选定机制 C 的完整语句（ISSUANCE 证明电路）

用户对 RA 证明（公开输入：纪元根/撤销根/伪名 N/会话承诺 cm；见证：salt、
id_number、cert_level、sn 原文、id′、pk′、主凭证签名 (r,s)@M_A）：

1. **已注册**：我持有 RA 对主凭证 M_A 的有效 SM2 签名（电路内验签——与 AUTH
   电路同一构件），且 C=SM3(salt‖cert‖class‖id‖sn_h) 与 M_A 的 C 槽一致；
2. **未吊销**：handle=SM3(C) ∉ 撤销 SMT（现成 64 环构件，与 AUTH 同式）；
3. **未过期**：M_A 的 exp_u ≥ 当前时刻（电路已有时效比较范式，实例 21 同族）；
4. **报文良构**：待签的 M_A′ 165B 三块 SM3 重算成立，其 C/pk′/id′ 槽与我方
   见证一致（SM3 三块构件现成——AUTH 电路本体）；
5. **配额伪名**：N=H(C‖salt‖epoch)——RA 对 N 判重计数。salt 为 CSPRNG 128bit
   且**不在 RA 库**（F1），故 RA 拖库侧无法从已知 C 反推枚举 N；N 在纪元内
   可链接（同一用户同纪元的多次签发申请共享 N）——**这是量化披露的妥协**，
   换取"每伪名每纪元 ≤20 张"的配额强制（纪元 24h 滚动=TTL 对齐，过期自然
   回收，替代现行"未消费∧未过期"的库面配额口径 F5）。

构件成本盘点（🟢全部来自 vendor 现成 weave）：SM2 in-circuit 验签一套、SM3
三块两套（主 M_A 与子 M_A′）、SMT 非成员一套、nullifier 原像一组。**估算
约束量 ≈ AUTH 的 1.5–2 倍（3–4 万约束级）、证明分钟级**——🟡估算值，P2 期
census 实测定谳，超预算则砍语句 1（改用 RA 公示的活跃承诺 SMT 根，加一条
onlyRA 的 setRegistryRoot 链面——链合约小改，二选一在 P0 评审定）。

### 4.4 签发仪式逐消息（v1 草案）

```
[预置] 钥份额仪式（一次性）：sk_RA → (d₁@RA域, d₂@签发代理域)；pk_RA 不变
[仪式] 用户 U、RA、代理 P（P 可与 RA 同机不同域分权，生产建议物理分离）
① U→RA: ISSUANCE 证明 π + N + cm=Com(e,ρ) + epoch
② RA: 验 π（电路外 plonk 验证，秒级）；N 判重/计数（每 N 每 epoch<20）；
   通过则开签发会话 sid，→P: 会话开启
③ U↔P: 协同签名 2PC（M_A′/e 仅 U 侧明文；与 cm 的一致性以承诺内绑定承担——
   协议细节与证明义务=§7-O1）
④ U↔RA: 协同签名 2PC 第二方份额交互（按所选协议拓扑 ③④ 可为三角或两两）
⑤ U: 合成 (r,s)，本地验 verify_digest(pk_RA, digest_e_bytes(M_A′), (r,s))
   通过后收货；RA 落会话台账：{sid, N, epoch, cm, 状态}——**零 M_A′ 零 pk′**
[出示] 与现状逐字节不变：门控验签/重算/查重/实例钉（F8）照旧
```

RA 会话台账（新表 `blind_issuance_sessions`）取代 `sub_credentials` 的签发面
角色；`sub_cred_hash_hex`/`message_hex`/`sig_hex`/`holder_pub_hex` 四列全部
不再签发期产生。**一次性消费与查重本就键在出示面**（applications+链上
usedSubCreds，F8）——出示后平台看到的是"被出示的那一张"，与今天的出示面
暴露完全同口径，无新增泄露。

签发面数据 schema 前后对照：

| 列（现行 sub_credentials） | 盲签后（blind_issuance_sessions） | 隐含 |
|---|---|---|
| credential_id（实名外键） | **删除**——配额改键 N | 外键链断裂=拖库不可重放的根 |
| sub_cred_hash_hex=SM3(M_A′) | **删除**（cm=Com(e,ρ) 承诺替代） | 签发面不再持有出示键 |
| message_hex / sig_hex | **删除**（2PC 内流转，不落盘） | M_A′ 签发期不出用户端 |
| holder_pub_hex | **删除** | pk′.x 不再入撤销传播（§5.3） |
| consumed / expires_at | 纪元滚动替代（N 计数 24h 归零） | 配额回收语义等价 |
| ——（新增） | sid、N、epoch、cm、状态（ok/abort） | 中止留痕入审计面 |

**盲签两性质的操作化定义**（非形式化，供 P0 评审对齐口径）：
- **blindness（盲性）**：RA（及代理）在仪式中的全部视图（π、N、cm、2PC 掩码
  值、abort 决策）与"签发了哪张 M_A′"在多项式时间内不可区分地关联——即给定
  事后公开的出示材料，无法以优于掷币的概率把它配回某个签发会话；
- **one-more unforgeability（多签一个即破）**：完成 n 次签发会话后，用户最多
  得到 n 个可验签 (r,s)——打破它=从会话中"提取"额外签名，ROS 型攻击即此形态。

## 5. 其余五问应答

### 5.1 SM2 盲签构造选型（六问之二）

结论重述：🟢成熟可用的是**模型与基准**（Chaum 1982 概念；Pointcheval–Stern
2000 两性质形式化：blindness + one-more unforgeability）；🟡可用族是**盲
Schnorr 修复系**（ROS 攻击链：Wagner 2002 子指数→Benhamouda et al. EUROCRYPT
2021 多项式时间→Fuchsbauer–Wolf 2022 ROM 可证明修复方向）与**两方协同签名**
（ECDSA Lindell 2017；SM2 域 M2A/Tan 2023 文献）；🔴开放问题是**SM2 原生盲签
的无标准可证明构造**（§3.2 附录推演支持排除）。配对曲线族（BBS+/PS）因 SM2
曲线非配对友好+裁决一（电路锚 pk_RA）双重排除。
**abort/extract 攻击面与防括**：恶意签名人可选择性中止（abort）事后将中止
视图与公开签名配对去匿名；恶意用户可试图从 n 次会话提取 n+1 个签名（one-more
伪造，ROS 即此形态）。防括（🟡组合惯例+🟢运维面）：**一期一签**（一资格证明
一签发会话，无挑战组合自由度）；**每伪名每纪元限 20**（签发节流，abort 观察
样本受限）；**中止留痕**（会话台账记 abort 状态，入审计面——中止策略本身
可被事后审查）；签发代理与 RA 分域（abort 协调需两域串谋）。

### 5.2 电路影响面（六问之三）

**AUTH 电路：零改动。**逐项核对：M_A′ 165B 布局不变（裁决一）；pk_RA/键不变
（F9 Z_A 常量锚不漂）；实例面 0..2/12..17/19..25 语义不变；受理门控的验签与
重算路径（F8）逐行不变。

### 5.3 吊销/追踪兼容（六问之四）

**追责路径：全通。**实名仍在 RA：组织级 TCB 最小保留字段（签发面新增字段
一律为零）——`username`、`id_number_hash_hex`（B7 黑名单判重）、`id_cipher`/
`id_store_cipher`（通道①②）、`serial_hex`（设备交叉审计源）、`status/
expires_at`；这些均在**注册时刻**合法获得，与子凭证盲化无关。固件事件→
logWarrant→双控（admin+auditor 两钥同签）→warrant_unlock→logWarrantUnlock
（F7）逐环不变；`revoke_by_username` 按人级联、黑名单禁入、B6 双控恢复全部
照旧。**唯一的语义退化=撤销传播**：F6 的 pk′.x 并入依赖 RA 知道每张子凭证的
pk′——盲化后 RA 不知道 ⟹ 已签发未消费的子凭证在 TTL 内仍可出示。**如实
量化**：暴露窗 ≤ min(子凭证 TTL, 主凭证剩余有效期)；建议盲签纪元内
**TTL 从 24h 降为 6h**（与政策授权窗上限对齐——受理门控 ⑥ 本就要求
exp_u ≥ t_end，6h TTL 不伤诚实流），则"吊销后残余飞行授权 ≤6h"为明码边界，
答辩口径 replaces 现行"即时数学拒绝"表述。**未来收紧**（🔴立 v2 评审）：出示
面电路加第二 SMT（签发期伪名撤销集）——这是 AUTH 电路换代，本草案不做。

## 附录 A：SM2 原生盲化两条自然尝试的失败推演（裁决二依据）

记验签恒等式：给定摘要 e、签名 (r,s)，t=r+s，隐点 K′=[s]G+[t]P，接受当且仅当
r = e + x(K′)。签发侧对应：K=[k]G，k = s + d·t。

- **尝试 1（摘要缩放）**：用户取随机 γ，送 e*=e/γ；期望输出 (γr*, γs*)，
  隐点 K′=γK。验证：r=γr*=γ(e*+x(K))=e+γx(K)，而需要 r=e+x(γK)——因
  **x(γK) ≠ γ·x(K)**（x 坐标非线性）恒不成立。缩放路线死。
- **尝试 2（仿盲 Schnorr 挑战平移）**：用户欲把隐点改为 K′=αK+βG，对应
  (r,s)=(αr*−β, αs*+β)（由分量线性反解）。代入响应恒等式要求
  σ + d(σ+ρ) = β 形态的修正项——其中含私钥 d 的线性组合，用户既不知 d，
  唯一自由解又退回 β=0=无盲化。盲 Schnorr 之所以可行，是其隐点 R′=αR+βG
  **独立于响应**存在两个自由度；SM2 的隐点被 (s,t) 唯一决定，自由度缺失
  即结构性障碍。绕过需引入额外交互轮/承诺机构——已超出"标准签名输出"
  （裁决一）边界。
