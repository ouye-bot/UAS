## 3.1 承诺 C 块查表化（预期 prove 97.6s→≈70-75s，−23~28%）

### 现状
CommitOne 形态的 C=SM3(salt16‖cert4‖class1‖id18‖sn_h16)（55B 单块）由
`sm3_compress_v2` 位级布尔体（ZONE0，plan_z_parts_single 分配）在电路内计算
——约占 AUTH 全语句约束的 45~55%（家族分解：验签体 16,554+EC 六循环
~20K+布尔 C 块 ~45-60K+杂项 ≈ 104,543）。

### 手术步骤（依赖序）
1. **PLAN 相**（sm2_full_statement_assemble.rs 的 `pc.is_some()` 分支）：
   - `c_circ = sm3_lookup_weave::chain_circuit(&[c_blk64])`（c_blk64=55B 报文
     的 SM3 填充块——host 侧已有 `commitment_c_auth` 同源计算，组装期可见 ✓）
   - `weave_alloc` 组数 3+smt_groups → **4+smt_groups**；msg_groups 3→**4**
     （第 4 组=C 块，需 msg-limb 桥接）；pconst 冲突处理：C 块 pconst 与三体
     pconst 可能不同 ⟹ weave_alloc 增第二 pconst 列+LutPlan 增
     `pconst_global_c: usize` 字段，weave_constraints/weave_proto_gates 的
     P_CONST 映射按电路参数化
   - 删除 `plan_z_parts_single` 调用与 ZuPlan/ZuRings 的 CommitOne 支路
     （sm3_compress_v2 保留两体形态不动——T1/merged 发布锚零触碰）
2. **WIRES 相**：`weave_core(c_circ, c_sub_plan)`（值播种+环翻译，已有泛型）；
   C 单例环（weave_wires ④b 的 msg_roots[1] 预开环）保持——c_cols 词格环
   是 D 体消息链的消费端
3. **EMIT 相**：
   - `weave_wires` 扩展或新函数处理第 4 组 msg 桥接：msg_roots_c[16]=
     salt_cols×4(秩 3800+)+true_cols×10(3804+)+pad×2(3824+)——**根表已存在**
     （plan_z_rings CommitOne 分支现成，搬移即可）
   - `weave_constraints` 对第 4 组发射（4 约束+8 lookup+16 msg recomp）
   - 摘要出口：C 块 digest 词→64 影子格（dgw 同款）→ recomb
     Σ2^{4j}·shadow==c_cols[k]（8 条，@b2_row_c）——c_cols 已在 D 体消息根环，
     环拓扑自然衔接
   - **θ 范围门保持**：b2_true_cols[0]@秩 3808 的 CommitOne 消息根环成员资格
     必须由 LUT msg 桥接自然提供（msg 桥接把根格环进 W_INPUT 等值类 ✓）
4. **锚换代**：结构断言 104,543→实测值（预期 ≈45-60K）；advice ±；lookups
   +8；四族回归+S1/e2e 重挂
