# 飞证 · 数据分级与生命周期（P1 交付文档，2026-09-23）

> 原则：①零身份红线——链上/平台库/回执表零身份列（模型级测试断言）；
> ②实名仅两处=RA 通道②密文（令状解锁依据）+审计台解锁展示（解锁完成后）；
> ③轨迹本体永不上链（只有链头与承诺）。

## 一、数据全景（五域 × 内容 × 可见方 × 保留期）

| 域 | 数据 | 可见方 | 保留期 |
|---|---|---|---|
| **链上**（FISCO BCOS 四节点） | masterCredHash 承诺、政策表 paramsHash/classRule、电路指纹 pin、授权记录（tokenHash/nonce/classId/altMaxM/时间窗/subCredHash/proofDigest）、检查点（链头+设备签名——🔴围栏态不在链上，仅存平台库投影）、事件哈希、令状哈希+scope、解锁留痕 | 联盟链全体成员（公开公示面） | 永久（append-only——撤销/变更亦为追加记录） |
| **平台库**（后端 PG） | applications（会话公钥/子凭证签名与哈希/nonce/计划承诺/时间窗/状态——零身份列）、receipts（回执码+ECIES 令牌密文）、auth_records（授权镜像索引）、warrants（案号/目标授权/解锁实名）、chain_events（链上事件投影） | 运营方（系统管理员） | 申请与授权记录=监管保留期（建议 ≥2 年）；回执密文=窗后可清理；事件投影随链增长 |
| **RA 库**（登记机构） | 实名映射密文（SM4-GCM(cred_hash → 姓名‖身份证‖**SN₁ 明文**，通道②信封 v3——设备交叉审计数据源）、凭证状态/配额/撤销表、私钥（sk 加密存储） | 仅登记机构（解锁需令状在案+协作函双控） | 永久（撤销与追责依据） |
| **用户本地**（浏览器） | 身份私钥（口令+恢复码双密文，见 docs/密钥库安全说明.md）、凭证材料（承诺/盐）、计划全文+盐、回执码、会话私钥（sessionStorage 关窗即焚） | 仅飞手 | 用户自管；清浏览器=需恢复码恢复 |
| **桥接本地**（地面站） | 令牌审计行/拒绝行（gcs_audit.db）、遥测样本与检查点（内存+链头）、计划仓 | 仅飞手（TCB 第①层——用户理论可改，固件围栏=第②层硬强制） | 本地自管 |
| **KMS/密钥面** | 四把链交易钥（ra/engine/auditor/admin）、引擎令牌钥、RA 签名钥、wrap 钥 | 进程内持有，无人可见明文（demo=域派生/env；生产=HSM+分发仪式） | 演示=会话级；生产=轮换周期 |

## 二、跨域流转（谁把什么给谁）

1. **登记**：用户 → RA：公钥+承诺哈希（实名与盐**不上行**）；RA → 链：masterCredHash；RA → 用户：承诺材料+盐（ECIES 密文，通道①）。
2. **申请**：桥接 → 授权服务：证明+公开实例+子凭证哈希+nonce+计划承诺（**计划全文与盐不出本机**；**见证材料不出桥接**）。
3. **授权**：worker → 链：recordAuth（tokenHash/nonce/classId/altMaxM/窗/subCredHash/proofDigest）；worker → 回执：ECIES(会话公钥) 加密令牌。
4. **追责**：审计方 → 链：logWarrant；RA → 审计方：随案协作函（加密 cred hash）；审计台展示：实名（解锁完成后）。

## 三、保留与删除语义

- 链上数据不可删（append-only；撤销=状态追加）；
- 平台库删除不影响链上留痕与第三方复验（判决件归档独立于库）；
- 判决件三件套（proof/vp/verdict）=可审计签发的证据载体，保留优先级最高（建议异地备份，见 backup_demo.py）；
- 用户侧"被遗忘"：本地清浏览器即全删；链上授权按时间窗自然过期、令状 append-only——监管保留期与个人删除权的边界=链上公示面（无身份，删除权不适用）。
