## 二、不可能性论证（四个引理，每条走到数学终点）

**公共设定**：承诺 ṽ_i = v_i + λ_i·m（现状，λ 列级）；验证方核验链 =
sumcheck（明文世界 + ρ·eq·m 项，x_eval 钉死 E_masked(v)(x)）→ 语义开口
（掩蔽世界）→ **去掩粘合**（verifier.rs:66-85 `claimed − λ_i·m_eval`）→
`evaluate(E_masked, adjusted) == x_eval`（verifier.rs:87-95）。

**引理 1（λ 公开 ⟹ 泄漏回归）**。若逐（列×开口点）标量 λ_{i,j} 明文入转录
（D18 代价模型"#(掩蔽列×开口点)×40B"的直译），且 λ_{i,j} = 该点真实消去
系数（d_{i,j}/m(p_j)），则该点残差 v_i(p_j) 可公开重算——与现状同泄漏。
∎（D18 §3.3 的 ε = E·p⁻¹ 计算，”条件 m(x)≠0 时开口对 λ 完美均匀“一句
**以 λ 私有为前提**；而代价模型又以 λ 公开为前提——**D18 证书 §3.3 的误差
模型与 §2.6 的代价模型互斥，此即路线①的内在矛盾**，原文标注"供论文线 D27
定谳"，本定谳书即对该开口的补足。）

**引理 2（λ 私有 ⟹ 核验断裂）**。若 λ（列级或点级）不公开，验证方的去掩
adjusted = claimed − λ·m 不可计算；把核验搬到掩蔽世界需要计算
E(ṽ − λm)(x)，其展开含 λ 的交叉项（积门 w₁·w₂ 产生 −(λ₂ũ₁+λ₁ũ₂)m +
λ₁λ₂m²），λ 未知则验证方无法配平——诚实证明也无法通过。∎

**引理 3（去掩差值段无锚 ⟹ 健全性崩溃）**。若改为证明方公开"逐 query 去掩
差值" d_{i,q}（声称 = 该点真实掩蔽贡献），验证方 adjusted = claimed − d 可
核验方程，但 d 与承诺世界无绑定（λ 无承诺；低秩基 Λ 的承诺只能锚 Λ 自身的
多线性延拓值，锚不住"逐点积向量 Λ∘m 的延拓值"——Merkle 承诺不支持线性组
合）。证明方可任选 d ⟹ adjusted = 任意 V̂ ⟹ E(V̂)(x) = x_eval 对 E 维自由度
恒可配平 ⟹ 承诺世界的 witness 与 sumcheck 世界的 witness 脱钩，健全性丢失。∎

**引理 4（盲化标量 + 配平项 ⟹ 完备性丢失或健全性丢失）**。若公开盲化标量
λ̃ = λ + r（r 逐点新鲜私有），hiding 恢复（残差 v − r·m 对读者均匀——模拟器
论证通过，这是 D18-Ω 的 hiding 核心），但 adjusted = v − r·m ≠ v，核验需要
r-交叉修正项 Δ = E(v−rm)(x) − E(v)(x)；Δ 依赖私有 r（且含 v）⟹ 无锚 ⟹ 回到
引理 3，或验证方以公开挑战 ζ 替换 λ 核验 P(ζ)=0 ⟹ 诚实方 P(ζ)≠0（P ≢ 0）
⟹ 完备性丢失。∎

**推论（架构级不可能）**。在 ①非交互公开 FS 转录 ②Merkle PCS（不可组合
承诺）③单 sumcheck + 非线性表达式 ④多线性约束全域（无 vanish 盲化空间）
四约束下，**语义开口主面（query 级点值）的 HVZK 与粘合核验不可兼得**——
halo2/Plonk 靠"多项式恒等式两边同盲化"跨过的墙，在多线性全域约束 + Merkle
承诺的世界里不存在对应物。S6 面与节点面（两个侧面）可以闭合（见 §三），
主面（query 面）不行。∎

## 三、可实施的最大降级方案：D18-Ω（设计书，未实施）

**思路**：λ 向量化 + 低秩基 + 内积 sumcheck 锚——"每列一把遮罩标量"升级为
"每列一支遮罩向量"（每个潜在开口点=布尔点一把新鲜标量的秩 K 组合形态）：

1. **承诺面**：ṽ_i[b] = v_i[b] + λ_{i,b}·m[b]，其中 λ_{i,·} := Σ_{k<K} a_{i,k}·Λ_k
   （K≈8 支全局随机向量 Λ_k 私有并承诺；列系数 a_{i,k} 公开）。承诺面仍为
   D18-A 完美隐藏（λ 向量均匀）；编码点即时算（K 乘加/元素，承诺时延 +≈0.1s）。
2. **转录变更**：λ 段退役；a 段写入（K×num_masked×40B ≈ 4.2MB）；D 段写入
   （D[k][q] = ext(Λ_k∘m)(x_q)，K×#queries ≈ 24 值）。验证方自算
   d_{i,q} = Σ_k a_{i,k}·D[k][q]。
3. **D 的锚（健全性关键）**：三元内积 sumcheck——证
   Σ_{k,q} η^{k,q}·[Σ_b Λ_k[b]·eq(x_q,b)·m[b]] = Σ η^{k,q}·D[k][q]
   （η 在 D 段公开后挤出；终点开口 Λ_k(r) 与 m(r) 并入 batch_open 开口集，
   由 Λ/m 承诺锚定）。轮消息 ~KB 级，prover/verifier 时延毫秒级。
4. **验证方去掩**：adjusted = claimed − d_{i,q}（有锚 ⟹ 引理 3 不触发）。
5. **batch_open 组合面**：g′ 的掩蔽项 (Σc_i·λ_i)∘m → 系数向量组合
   λ_comb = Σ_k (Σ_i c_i·a_{i,k})·Λ_k，组合与物化路径域算术恒等。

**收益（诚实口径）**：
- **S6 码字投影面闭合**：λ 不明文 ⟹ Enc(ṽ_i)[j] − c·Enc(m)[j] 不可消（每列
  32 个投影 → 0）；
- **节点面闭合**：节点级掩蔽贡献未公开（D 只在 query 级）⟹ 2^d−1 个额外
  泛函/列 → 0；
- **query 主面保留**：adjusted = v(x_q) 公开可算——**与明文 HyperPlonk 完全
  同构的协议必需面**，ε_open 在 D18 严格模拟器口径下**仍 ≈ 1**。
- 体积 +≈5.5MB（16.1→≈21.6MB，落在任务书 17~35MB 预期内）；速度 +0.2~0.5s
  （±1s 内）；指纹换代上链 + 黄金向量重生成照常。

**工程量与风险**：vendor 四文件（hyperplonk/preprocessor/prover/verifier +
basefold 接口向量化）≈ 600–800 行核心改动 + 新子协议 ≈150 行 + 测试改造
（新鲜度门/线性残差门/e2e 门适配 + 新增"S6/节点残差不可算性"红绿测试）；
prove 级全量回归数轮。**不达任务书 ε 验收**是硬伤——宣称口径必须降级为
"S6+节点面闭合、query 面与明文协议同构"。
