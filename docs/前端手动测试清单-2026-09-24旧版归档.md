## demo 环境诚实边界（作为测试项验证）

1. **回执停在 waiting**：无验证 worker——ZK 验证是真实异步面，demo 不伪造 "ready"。
2. **取件 not_ready 拒绝**：同上，fail-closed 是正确行为；解密+验签的密码学正确性由
   跨语言 fixture 测试钉死（后端 Python 封发 ↔ 浏览器端解密验签，tests/lib/token.test.ts）。
3. **ARM 需真实令牌**：bridge 五查（签名/窗/计划/字段/nonce）在拿到 ready 令牌后全部
   真实执行（S1 彩排窗以预生成件+诚实标注接线）。
4. 审计台真链解锁全流程：`backend/scripts/scenario_S4.py`（真链 17 断言判决行）。
