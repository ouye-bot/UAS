## 一、承诺方案与掩蔽的语义

### 1.1 承诺方案（协议栈与参数面）

论证栈 = **HyperPlonk（多项式组合 + 零检查 sumcheck）⊕ Basefold PCS（多元线性
多项式承诺）**，类型级钉定于 `zksvc/src/prove.rs`：

```rust
type Pcs = Basefold<FpSM2, Sm3, ZkcVerifySpec>;   // prove.rs:61
type Pb  = HyperPlonk<Pcs>;                        // prove.rs:62
type T   = SM3Transcript<Cursor<Vec<u8>>>;         // prove.rs:63
```

| 参数 | 值 | 锚 |
|---|---|---|
| 开口重复挑战数 `reps` | **16** | `BasefoldExtParams::get_reps`（prove.rs:44-46） |
| 码率 `log_rate` | **1**（ρ=1/2，码字长 `n = 2^(nv+1) = 8192`） | 同上 `get_rate`（prove.rs:47-49） |
| 基码轮数 `basecode_rounds` | **0** ⟹ 折叠轮数 `nr = nv = 12` | prove.rs:50-52；basefold.rs:328 |
| 码型 | `"random"`（AES 流派生随机线性码，折叠点为 `x, −x`） | prove.rs:56；basefold.rs:318 |
| 基域 | `FpSM2`，`|F| = p ≈ 2^256` | plonkish_sm2_probe |
| 转录/承诺哈希 | **SM3**（GB/T 32905-2016，256bit 输出；标准向量对拍锁定） | hash.rs:81-83（sm3_digest_matches_gbt32905_vectors） |
| 透明性 | setup 种子公开常数派生（`SEED_SETUP^nv`）；编码表与公共盐链由调用方种子跨进程可复现；**无陷门** | prove.rs:443；basefold.rs:302-335 |

透明 setup 对 hiding 的意义：承诺的绑定力与遮蔽力**只依赖盐与掩蔽的运行时
随机性**，不依赖任何"可信设置的秘密"——不存在因 setup 泄密而击穿 hiding 的面。

### 1.2 掩蔽对象清单（哪些多项式被掩蔽）

掩蔽架构 = **共享掩蔽列 + 每列标量**（D18 Phase 3"三世界统一"，preprocessor.rs:13-27、81-139）：
均匀随机多项式 `m ← F^(2^nv)`（`MultilinearPolynomial::rand(pp.num_vars, OsRng)`，
hyperplonk.rs:253）与每掩蔽列一枚独立均匀标量 `λ_i ← F`（hyperplonk.rs:245-248）；
掩蔽列承诺 `ṽ_i := v_i + λ_i·m`。

| 列族 | 是否掩蔽 | 理由 | 锚 |
|---|---|---|---|
| witness 列（advice，含签名/身份/撤销成员等秘密） | **是** | 见证派生，全部秘密来源 | preprocessor.rs:105-108 |
| lookup m 列 | **是** | witness 派生（查表计数列） | hyperplonk.rs:311-318 |
| lookup h 列 | **是** | witness 派生 | hyperplonk.rs:338-353 |
| 置换 z 列 | **是** | z 开口是 witness 的确定性泛函——不去掩则跨出示累积泄漏通道不闭 | hyperplonk.rs:338-339 |
| 实例列 / 预处理列 / 置换 σ 列 | 否 | 公开信息（语句公共面），掩蔽无义 | preprocessor.rs:16-17 |
| 掩蔽列 m 本体 | 独立承诺 | 进入验证以支撑去掩与 sumcheck 掩蔽项 | hyperplonk.rs:255 |

sumcheck 侧同步掩蔽：零检查表达式追加 `ρ·eq(X,y)·m(X)` 项（preprocessor.rs:124-127），
sumcheck 初始和 = `ρ·m(y)`，且 **`m(y)` 先行上链、先于挑战 ρ 挤出**（hyperplonk.rs:379-384）
——初始和由 PCS 开口钉死，敌手无法为零和通道虚配掩蔽值。

时序前提事实（FS 序之根）：**`λ` 明文写入转录与 `m` 承诺上链发生在任何挑战导出之前**
（hyperplonk.rs:236-255 先于全部 `squeeze_challenges`），β/γ/α/y/ρ 各轮挑战依次由
**掩蔽后**的承诺导出（hyperplonk.rs:284-318, 379-397）——证明者无法按见证信息挑选挑战。

熵源纪律：`λ/m` 取**内部独立熵源 OsRng**，禁用调用方 rng——生产调用方传固定种子
（`StdRng::seed_from_u64(0x5317_0002)`），若 λ/m 取自调用方 rng 则 λ 明文段跨证明恒同 =
全局可链接（hyperplonk.rs:219-223 注释；新鲜度门 `phase3_mask_freshness_fixed_seed_two_proofs`
以"首差异必须落在实例+λ 区"把该回归钉死，hyperplonk.rs:594-659）。

### 1.3 MASK_OFF 的语义边界

关闭途径**唯一且自述**（hyperplonk.rs:239-254；prove.rs:116-129）：

1. **语义**：env `MASK_OFF` **存在即关**（`var().is_ok()`，置 `"0"` 也是关）⟹ `λ_i ≡ 0`
   且 `m ≡ 0` ⟹ `ṽ = v`：承诺、转录、开口全部退化为**明文见证**。
2. **同构性**：证明布局/尺寸/验证路径与掩蔽态逐字节同构，验证方零改动——消融
   测量值 = prove 时间差（hyperplonk.rs:240-242）。因此 MASK_OFF 不是"另一个协议"，
   而是**同一协议在掩蔽熵置零处的诊断/对照构型**。
3. **自述**：判决件 `verdict.json` 的 `mask` 字段（on/off）+ 置位时 stderr 警条
   （prove.rs:394-399, 559）——"静默关闭、外观不可检"被杜绝；自述与消费方分叉 =
   判决件说谎，比不披露更糟（prove.rs:116-119）。
4. **定理适用边界**：本文一切 hiding/零知识命题**以 `MASK_OFF` 未置位为前提**；
   MASK_OFF 构型下系统明确**不主张**零知识（证明可链接，判决件已自述）。

### 1.4 transcript = SM3 的 Fiat–Shamir 变换（机制形式化）

`SM3Transcript = FiatShamirTranscript<Sm3, Cursor<Vec<u8>>>`（transcript.rs:111, 113-117）。
吸收/挤出一对原语：

```text
absorb(x):  state ← SM3_state_update(x)                    // 实例、域元素、承诺块
squeeze():  h ← state.finalize_fixed_reset();              // 滚动状态（sponge 式）
            state.update(h);  challenge ← fe_mod_from_le_bytes(h)   // 256bit → Fp
```

吸收面与次序（写读两侧同站对称，任何一环缺吸收 = 挑战对证明者可预知）：

| 站点 | 内容 | 锚 |
|---|---|---|
| 实例吸收 | 公开实例域元素（prove/verify 同吸收） | hyperplonk.rs:224-233, 426-431 |
| λ 明文 + m 承诺 | `(salt, root)` 对写入并吸收，先于任何 squeeze | hyperplonk.rs:245-255, 433-435 |
| D1 承诺身份 | 一切先于挑战的承诺 `(salt, root)` 逐对吸收——修复"哈希块承诺只搬字节不吸收 ⟹ 挑战可预知" | basefold.rs:1908-1922 |
| D2 批量语句 | 标签/点数/声称数/全部点坐标/每条 (poly,point,value) 先于组合挑战 t | basefold.rs:1924-1948 |
| 折叠轮 | 每轮 `(盐,根)` 吸收后挤本轮折叠挑战 | basefold.rs:1134-1144 |

语义定位：FS 变换把"验证方均匀掷骰"替换为"SM3 对公开转录前缀的确定性输出"。
其安全地位是**编译假设**而非无代价事实——见 §3.1 口径声明。

## 二、HVZK 定理形式化

### 2.1 安全模型与口径声明（标准模型 vs ROM，先立规矩）

- **零知识口径 = HVZK（诚实验证者）**。FS 编译后的验证方是确定性公共硬币算法，
  "验证方视图" = 转录本身；故本文零知识命题一律对**转录分布**陈述。
- **两层面、两种模型**：
  - **交互面（公共硬币协议，把 FS 挑战视为外部均匀骰）**：掩蔽的覆盖性论证是
    **信息论/统计**的（一次一密 + 线性覆盖），在**标准模型**成立，不依赖任何
    哈希假设。
  - **非交互面（FS 编译后）**：把均匀骰换成 SM3 输出，其不可区分性归约为
    **SM3 的随机预言启发式（ROM 口径）**；在标准模型中 SM3 不是随机预言机，
    非交互面**不做标准模型主张**——这是如实的口径边界，不是弱化。
- **不主张**：恶意验证者零知识（本协议验证方确定性，无验证方随机性可言）、
  模拟可提取性（见 §5.2）、`nr < nv` 构型（见 §5.3）。

### 2.2 定义（两世界、模拟器、HVZK）

记协议 `Π_mask` 为 MASK_OFF 未置位的 HyperPlonk+Basefold（§1 参数面）。
对语句 `x` 与见证 `w`，诚实证明者内随机带 = `(λ, m, {salt_t}) ← OsRng`。

- **真实世界** `Real(x, w)`：转录 `T ← ⟨P(x,w; λ,m,salts), V(x)⟩`。
- **模拟世界** `Sim(x)`：`T' ← P(x, w ≡ 0; λ', m', salts')`——**模拟器 = 诚实证明者
  跑在零见证上，掩蔽熵重新抽样**。注意模拟器是"直线上"的：它不编程转录、
  不编程哈希输出，逐站走与真实证明者相同的线路。
- **定义（HVZK）**：`Π_mask` 是误差 `ε_zk` 的 HVZK，若对任意（无界/有界，分见
  统计/计算口径）区分器 `D`：

```text
   | Pr[ D(Real(x,w)) = 1 ] − Pr[ D(Sim(x)) = 1 ] |  ≤  ε_zk
```

### 2.3 定理 D18-A（承诺面链接隐藏——T1.3b 定案的定理化）

**定理 D18-A**。设 `MASK_OFF` 未置位。对任意两见证 `w ≠ w'`、任意两列族取值，
承诺面边际分布满足：

```text
   SD( Comms(λ,m,salts; w), Comms(λ,m,salts; w') ) = 0
```

即：承诺序列（各列盐化根 + λ 明文段 + m 承诺）的分布**与见证无关**（统计等价，
完美隐藏）。

**证明骨架**。固定 `w, w'`。① `λ` 段与 `w` 无关（OsRng 均匀、独立采样）——恒等。
② `m` 与 `w` 无关——恒等。③ 对每个承诺列：`ṽ = v + λ·m` 中 `λ` 均匀 ⟹ 对固定 `m`，
`v ↦ ṽ` 是平移双射；再叠加每树独立 fresh 盐（32B，OsRng，basefold.rs:2002-2007），
根 = `H(salt‖Enc(ṽ))` 对 `ṽ` 的依赖被 `salt` 的均匀性以一次一密方式吸收——两世界
根分布均与 `w` 无关。④ 并集界：`T` 棵树盐重复概率 `≤ T·2^-256`（§3.3），属新鲜度
误差而非见证依赖项。∎

**机器锁**：未盐化树的根重合度实测 52.9%/73.9%/99.3%（恒定列 standalone/merged/T1）
= 指纹通道存在的负证；盐化后同见证两次 prove 字节互异、首差异落在实例+λ 区
（新鲜度门）；端到端二次 prove SM3 摘要互异（SV-1 判决行 / 性能档案 R1）。

### 2.4 引理 D18-B（sumcheck 轮消息覆盖）

**引理 D18-B（线性覆盖）**。设固定挑战（含 ρ）与 `m ≠ 0`。sumcheck 轮消息满足
线性分解

```text
   msgs(v, m)  =  msgs(v, 0) + ρ·G(m)，        对任意见证 v；
   msgs(0, m)  =  msgs(0, 0) + ρ·G(m)，
```

其中 `G: F^(2^nv) → F^(nv·stride)` 是 `m ↦ (ρ·eq·m 项诱导的逐轮消息增量)` 的线性
映射，`stride = 表达式度数 + 1`。**若 `G` 满秩（秩 = nv·stride），则轮消息面的
两世界分布统计距离为 0**（对均匀 `m`，`G(m)` 在像空间均匀，一次一密覆盖见证项）。

**证明骨架**。① 线性性：`ρ·eq(X,y)·m(X)` 对列向量线性，sumcheck 轮消息是列的
多重线性泛函 ⟹ 分解式对列逐项成立（零检查表达式其余项不含 `m`）。② 覆盖：
对任意 `v`，取 `m*` 使 `G(m*) = msgs(v,0) − msgs(0,0)`（满秩假设下存在），则
`m + m* ~ 均匀` 且 `msgs(v, m+m*) = msgs(0, m)` 的分布——两世界轮消息同分布。∎

**机器锁与证据状态**：线性分解恒等式由
`phase3_sumcheck_msgs_linear_residual`（hyperplonk.rs:662-774）在 k=3 小档四组重放
逐位锁定：`msgs(v,m) − msgs(v,0) == msgs(0,m) − msgs(0,0)` 对任意 witness 成立，
且"整轮为零 ⟹ 无覆盖力"的非退化断言在案。**满秩性的解析论证（秩 = nv·stride）
尚未成文**——评审 P2-1 已立项（"覆盖性/秩论证"，A-密码与性能 2026-09-24）；
量级直觉：`G` 的定义域维 `2^nv = 4096` ≫ 值域维 `nv·stride ≈ 10^2`，退化到秩亏
需 `G` 的结构恰好共线，非退化门排除了"整轮映射为零"这一最粗退化。
本文将"满秩 ⟹ 完美覆盖"作为**引理的条件**如实标注，不以直觉替代证明。

### 2.5 定理 D18-C（HVZK 主定理，条件版）与开口面覆盖条件

**开口面覆盖条件（C-Open）**。记 `Rev(T)` 为区分者可从转录 `T` 重算的全部域元素
揭露：语义开口值（含 `m` 在各旋转点与 `y` 的镜像开口）、S6 逐列叶值对、`λ` 明文段、
`m(y)`。**C-Open：对任意 `w, w'`，`Rev(Real(·,w))` 与 `Rev(Sim(·))` 的分布满足
`SD ≤ ε_open`。**

**定理 D18-C**。设 `MASK_OFF` 未置位、引理 D18-B 的满秩条件成立、且 C-Open 以
`ε_open` 成立，则在标准模型（交互面）`Π_mask` 是误差

```text
   ε_zk  ≤  ε_open + E·p^{-1} + p^{-2^nv}
```

的 HVZK，模拟器 = 诚实证明者@`w ≡ 0`（§2.2 构造）。经 SM3-FS 编译后，在 ROM
口径下非交互转录计算不可区分到同阶误差加 SM3 相关性项（§2.1 口径声明）。
其中 `E` = 转录中语义开口值总数（服务档实测量级 `E ≈ 2.96×10^4`，评审 A 批
batch_open 对数口径），`p^{-1} ≈ 2^-256`，`p^{-2^nv} = p^{-4096}`。

**证明骨架（游戏序列）**。

```text
G0 = Real(x, w)                                   真实世界
G1:  换 (λ,m,salts) ← 新鲜抽样                     合法性：与 G0 同分布（都是 OsRng 新鲜熵）
G2:  轮消息面 msgs(v,m) → msgs(0,m)               合法性：引理 D18-B，SD = 0（满秩）
G3:  开口/承诺面 Comms·Rev → 模拟世界              合法性：C-Open（SD ≤ ε_open）
     承诺面余量：定理 D18-A（SD = 0）
G4:  剩余随机化面（初始和 ρ·m(y)、折叠链、S6）      m 均匀 ⟹ ρ·m(y) 均匀；逐项一次一密余量
G5 = Sim(x)                                       模拟世界
   逐步三角不等式求和 ⟹ ε_zk ≤ ε_open + E·p^{-1} + p^{-2^nv}
```

`E·p^{-1}` 项 = 每个语义开口点的一次一密失败余量（`P[m(x)=0] = 1/p`，见 §3.3）；
`p^{-2^nv}` 项 = 掩蔽多项式整体为零的退化概率。

**FS 编译步（G5 之后）**：非交互转录中挑战由 SM3 导出。模拟器直线性（不编程
挑战）使编译不依赖可编程 ROM——只需"SM3 输出在区分者视角与真随机计算不可
区分/满足相关性难解性"。这是**编译假设**，在 ROM 口径下成立；标准模型中
SM3 的 CI 性质无证明，本文如实不下结论。

### 2.6 C-Open 的当前状态——本证书自检发现（定理化表述）

**自检结论**：C-Open **在当前部署形态下不成立**。这不是新缺陷报告，而是把
"覆盖性论证"从口号化为可检验条件后暴露的精确边界（与评审 P2-1"掩蔽缺形式化
论证、覆盖性待成文"同根，本文将其定形到开口面）。

**命题 D18-E（开口面去掩可见性）**。`λ` 明文入转录、`m` 的镜像开口与 S6 叶值对
公开 ⟹ 对任意转录读者，去掩残差

```text
   R_i(x) := claimedᵢ(x) − λ_i·claimed_m(x)  =  v_i(x)
   R̂_i(j) := pairᵢ(j) − λ_i·pair_m(j)        =  Enc(v_i)[j]   （S6 查询位置 j）
```

是**可公开重算的明文见证泛函**——与 MASK_OFF（明文协议）在开口面**同泄漏**
（掩蔽不增加开口面泄漏，也未减少）。相应地，构造区分器 `D*`："重算全部残差，
存在非零即输出 1"。在 `Sim(x)`（w≡0）下残差恒零 ⟹ `D*` 恒输出 1；在
`Real(x,w)`（一般非零见证）下残差 = `v_i(·)`，非零概率 ≈ 1 ⟹ `D*` 优势 ≈ 1。
故两世界转录**可高效区分**，`ε_open ≈ 1`。

**严重度定性（不夸大、不缩小）**：
- 该缺口是"**模拟不可达**"（w≡0 模拟器不模拟开口面），不是"见证恢复"：
  残差给出的是**已揭示点上的逐点线性泛函**（每掩蔽列 1–3 个语义开口点 +
  16 位置×2 码字线性投影），不直接重构整列；其隐私量级 = 明文 HyperPlonk
  上游开山即有的开口面状态，D18 掩蔽未使其恶化。
- **已闭合面不受影响**：链接/指纹面（定理 D18-A，T1.3b 目标）与轮消息面
  （引理 D18-B 机器门）的闭合是本批 D18 的实绩，负例与门均在案。
- **修复路线**（供论文线 D27 定谳，按代价升序）：
  ① **逐（列，点）新鲜标量** `λ_{i,j}`：把每列一枚标量改为每（开口点）一枚，
     一次一密按点恢复，C-Open 达 `ε_open = E·p^{-1}`；代价 = 转录增
     `#(掩蔽列×开口点)×40B` 量级标量段；
  ② **开口面独立掩蔽**：m 在开口点改用逐点独立随机值承诺（等价于①的承诺侧
     形态）；
  ③ **组合开口去 λ**：S6/语义开口改走组合承诺链，使逐列残差不可线性分离
     （需重组验证方程，改动面最大）。

### 2.7 命题 D18-D（掩蔽不损健全性）

**命题 D18-D**。掩蔽开启与关闭两种构型的验证语义恒等：验证方以 `λ` 去掩
（`w_i(·) = ṽ_i(·) − λ_i·m(·)`，`rotation_eval` 对开口值线性 ⟹ 先插值后减与先减后
插值等价；verifier.rs:64-85）后，被核方程与明文形态逐条相同（"E6 语义逐字保持"，
verifier.rs:32-41）；sumcheck 初始和 `ρ·m(y)` 由 `m(y)` 先行上链 + PCS 开口钉死
（hyperplonk.rs:379-384, verifier.rs:96-101）。故 `ε_sound(Π_mask) = ε_sound(Π_plain)`：
**掩蔽只加熵、不改约束**，健全性归约到明文 HyperPlonk+Basefold 论证（其 FS 绑定
修复 D1/D2 与 Fix A/B 缺口闭合的负例均在案，见 §6）。∎

## 三、参数与安全档位（诚实推算，标注推导）

### 3.1 基础量

```text
p = 2^256 − 2^224 + 2^192 + 2^96 − 1，  |F| = p ≈ 2^256
nv = 12（k=12，poly_size = 4096；性能档案 2026-09-30 服务档实测）
码字长 n = 2^(nv+log_rate) = 2^13 = 8192；折叠轮数 nr = nv = 12（basecode_rounds=0）
reps = 16；码率 ρ = 1/2
```

### 3.2 健全性误差量级（两口径并存，如注记 §2.2 分层）

**口径一：挑战猜测计数下界（量级直觉层，注记原口径）**。FS 挑战为域均匀元素，
不知见证的伪造者每开口须猜中新鲜挑战，单点 `≤ p^{-1} ≈ 2^-256`；`t = reps = 16`
次独立挑战并界（union bound）：

```text
   ε_guess ≤ 16 · 2^-256 ≈ 2^-252
```

**口径二：编码距离层（Basefold 型 PCS 的支配项）**。码率 1/2 的 q 元随机线性码
（q ≈ 2^256）相对距离集中在 GV 界附近，q 大时 `GV → 1 − ρ = 1/2`，取 `δ ≈ 1/2`：
敌手在某一折叠轮以错误折线通过位置核对，须让 16 个查询位置同时落在与真码字
`δ`-接近的邻域，单层误差 ≈ `(1−δ)^reps = 2^-16`；全折叠链保守并界：

```text
   ε_code ≤ nr · 2^-16 = 12 · 2^-16 ≈ 2^-12.4
   （更紧的"首次失配轮"论证给单层 2^-16；两者都是量级直觉）
```

**口径声明（与注记逐字同纪律）**：以上是初等诚实算术，供量级直觉；batched
folding 的严格知识错误界与覆盖条件（D27 定谳 `ε_batch = ε_open` 及绑定三类）
**以论文线交付声明为权威**，本文不重复推导。两口径取支配项，系统当前部署的
健全性档位由**编码距离层**支配（2^-12 ~ 2^-16 量级），挑战猜测层 2^-252 是
其在"FS 挑战不可预知"前提下的下界直觉——这与注记 §2.2 的分层口径一致。

### 3.3 零知识误差量级（对 §2.5 各误差项逐项推算）

| 项 | 推导 | 量级 |
|---|---|---|
| 单点一次一密余量 | `m(x)` 为均匀多项式在点的取值 ⟹ 均匀，`P[m(x)=0] = 1/p`；条件 `m(x)≠0` 时开口对 λ 完美均匀 | `2^-256`/点 |
| 开口面总计 | `E ≈ 2.96×10^4`（batch_open 声称对数，评审 A 批实测口径）⟹ `log2(E)=14.85`，`E·2^-256` | `≈ 2^-241.1` |
| m 整体退化 | `P[m ≡ 0] = p^{-2^nv} = p^{-4096}` | `≈ 2^-1048576`（天文） |
| 盐重复（新鲜度） | `T` 棵承诺树（≤ 承诺列数 4.6×10^3 上界；交织档实际批次数更小）⟹ `T·2^-256` | `≤ 2^-243.8` |
| 轮消息面 | `G` 满秩 ⟹ SD = 0；秩亏概率（若 G 近随机投影）`≈ p^{-(4096−10²)}` | `≈ 0`（条件于满秩引理） |
| **开口面覆盖条件 C-Open** | **命题 D18-E：当前形态 `ε_open ≈ 1`（模拟不可达）** | **支配项，见 §2.6** |

**如实结论**：在"链接隐藏 + 轮消息覆盖"两子面上，零知识误差为 `2^-241` 级或
统计为零；**全转录 HVZK 的误差当前由开口面覆盖条件支配**（§2.6），修复路线①
落地后全转录 `ε_zk ≤ E·p^{-1} + p^{-2^nv} ≈ 2^-241`。

### 3.4 SM3 面推算（不拍脑贷的三笔账）

1. **抗碰撞**：SM3 输出 256bit ⟹ 生日界 `2^128`；折叠链/Merkle 认证的伪造面
   受此约束——256bit 安全预算内不成短板。
2. **FS 挑战 mod p 偏斜（诚实算术）**：`squeeze` 取 256bit 哈希输出 `X ∈ [0,2^256)`
   对 p 取模。因 `2^256 < 2p`，前 `r = 2^256 − p = 2^224 − 2^192 − 2^96 + 1` 个域元素
   被抽中概率 `2/2^256`，其余 `1/2^256`，每挑战统计偏差

```text
   TV = r / 2^256 ≈ 2^-32
```

   每证明挑战数 `~70`（β/γ/α + y(12) + ρ + sumcheck(12) + batch t(≤15) + 折叠(12) + reps(16)）
   ⟹ 全证明累计偏斜 `≤ 70·2^-32 ≈ 2^-26`。对 2^128 预算可忽略；作为拒绝采样
   缺失的已知微偏如实记录（修复不必要，记录以示诚实）。
3. **查询位置映射无偏**：查询下标 = `u32(challenge) mod n`，`n = 2^13` 整除 `2^32`
   ⟹ 条件于挑战均匀，位置精确均匀（无 mod 偏斜）。

## 四、已知边界：定理化表述与证据状态（安全注记 82-85 行五项 + 自检新增）

### 4.1 ① RBR（逐轮健全性）假设

- **定理化**：FS 编译保持知识健全性的标准充分条件是协议满足逐轮健全性
  （round-by-round soundness）：存在轮状态谓词 `RBR_k`，使敌手从未达"目标状态"
  出发、在第 k 轮后进入目标状态的概率 ≤ 该轮知识误差；FS 后非交互知识误差
  ≤ Σ_k ε_k^(RBR)。
- **当前证据状态**：**骨架 + 机器锚，无成文定理**。机器锚三层：D1（承诺身份
  先于挑战吸收，堵"挑战可预知"）、D2（批量语句先于组合挑战，堵"双假声称按
  权重相消"）、缺口 A 粘合等式（内层声称 `eval == g_prime_eval`，堵"声称与承诺
  链脱钩"）+ E3 伪造求值负例 Fix A/B 后确定性 REJECTED 2/2。严格 RBR 定理化
  （Basefold 折叠轮状态谓词显式给出）= 论文线 D27 交付物。
- **归属**：D27 权威。

### 4.2 ② 模拟可提取性（simulation extractability）

- **定理化**：存在 PPT 提取器 `Ext`，对任意产出可接受证明的 `P*`，能从
  `(P* 的视图, 转录)` 提取满足语句的 `w`，失败概率 ≤ 知识误差。SE 是"证明不可
  移植/不可重放伪造"类命题的前提。
- **当前证据状态**：**未主张**。本系统交付面是 HVZK（不可区分性，§2）；
  SE 以知识健全性（依赖① RBR）为前提，当前无定理亦无反例。部署面对抗
  "转录移植"的实际闸门是语句钉（实例钉 + 判决件 SM3 先拒 + 指纹对照），
  属工程闸门非密码学 SE。
- **归属**：D27 权威。

### 4.3 ③ nr < nv 熵边界

- **定理化**：本文 §2 全部定理在 `nr = nv`（`basecode_rounds = 0`）构型下陈述。
  当未来启用 `nr < nv`（基码轮次 > 0）时，末轮 oracle 为 `2^(nr+log_rate)` 维
  部分折叠向量**明文出证**，并伴随 S5 段（bh+eq 明文补写，basefold.rs:701-704,
  1149-1156）——该构型下掩蔽列的熵覆盖关系未被任何定理覆盖。
- **当前证据状态**：**构型边界显式声明 + 负例锁**。生产档不触达（`nr=nv=12`）；
  `nr=nv` 时末层必为重复码字，Fix B 断言 `final_oracle` 常量性（basefold.rs:3557-3563）
  把"非常量 = 自由对象伪造面"机器钉死。
- **归属**：D27 权威（本文补充了定理适用范围的显式声明）。

### 4.4 ④ 部署构型

- **定理化**：本文定理按**承诺方案语义**陈述，与 PCS 三部署开关
  （`PCS_INTERLEAVE` / `PCS_BATCH_DEDUP` / `PCS_VERIFY_STREAM`）及交织档叶形状
  **正交**——掩蔽语义在全部构型下布局逐字节同构（hyperplonk.rs:240-242）。
