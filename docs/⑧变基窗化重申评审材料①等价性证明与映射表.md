## 一、语句重排的数学等价性证明

### 1.1 重排命题

现役 E10 段在电路内证明（257 连续秩 3698..=3954，sm2_full_statement_assemble.rs:1587）：

```
rk = [r]apk （apk 作变量基点见证；r_bits 256 位逐位 double-and-add，
              β=rid_beta_c1 共享位环；基点绑定=apk staging 基/倍通道环）
C₂ = Id·G + rk （完全加 28 门 @row_ac2）
```

其中 **r=挑战（公开输入）、apk=公开实例 16/17**（pk′+pk_RA 的 staged 值，pk′ 亦是语句公开输出——E8 输出钉实例面）。重排命题：

> **命题 R**：将 `rk=[r]apk` 的电路内计算替换为「host 侧 native 计算 + 公开输入面钉入」，保留 `C₂=Id·G+rk` 完全加与 Id·G 通道不变，所得语句与原语句在以下意义下等价：对任意诚实见证，新语句的满足集与原语句的满足集在「rk 格取值」坐标上逐一对应（∀w：原语句(w, rk=[r]apk(w)) 满足 ⟺ 新语句(w) 满足且 rk 格=[r]apk）。

**证明**：(⇒) 原语句满足时 rk 格被 256 轮 double-and-add 约束链唯一钉死为 [r]apk（链初值 O=头钉 3 条、跨行传递 256×3 推、终值读口——勘误 #27 Fix R-a 的 write-next 语义，链上无自由度），C₂ 门对该 rk 值成立；新语句中 host 以同一 native 语义（affine_mul_bits，第五道防线权威）计算 [r]apk 并写入 rk 输入格，C₂ 门同样成立。(⇐) 新语句满足时 rk 格=[r]apk（host 计算且验证者可独立复算——见 1.2），C₂ 门成立；将 [r]apk 代回即构造出原语句的满足见证（原电路的循环约束对该 rk 值恒可满足——double-and-add 链对任意 (r, apk) 输入存在唯一执行轨迹）。∎

**等价性的密码学实质（评审实质议题——非形式事实）**：原语句中 rk 的正确性由**电路约束链密码学强制**（证明者无法在不知道满足链的情况下出一证）；重排后 rk 的正确性由**公开可重算性承担**——任何验证者（受理门/第三方）可用公开的 (r, apk) native 重算 [r]apk 并对拍 rk 格，**伪造 rk 的攻击面=伪造公开输入本身**（r/apk 的真实性与绑定在语句外部层——r 的挑战语义由 transcript 挤出、apk 的 pk′+pk_RA 绑定由 E8/E10 staged 基头环保留面承担）。**语义变更点（密码评审必审清单）**：

1. rk 从「电路内承诺的计算结果」降格为「公开输入」——若 rk 参与任何与秘密（Id）的非线性交互，须确认该交互只剩 C₂ 完全加（C₂=Id·G+rk 是 Id 的 Pedersen 型承诺加法——rk 公开不影响 Id 的 hiding，但 **binding 面从「rk 被电路计算锁死」变为「rk 是公开参数」——模拟器/提取器形态变化须重审**）；
2. 原循环的 β 位环（rid_beta_c1 共享 256 位格）随循环退役——β 环的其他成员（r·G 通道残留面/E9 空转消除后的位格）是否悬空须核查；
3. 实例面变化：rk 若入实例面（建议：rk.x/rk.y 两格公开钉）⟹ 实例 26→28，受理门 `_expect`/黄金向量/三值断言全换代（对照 2.2 材料① §五的换代清单工艺）。

### 1.2 公开可重算性的验证者侧闭环

重排后第三方可独立复验 rk：`(r, apk)` 均在公开面（r 从证明 transcript 挤出面/事件公示；apk=实例 16/17），native `affine_mul_bits` 重算 [r]apk 与 rk 格对拍——**与 e12 矩阵①′ 的 native 四步重放同一信任工艺**（现役已依赖 native 重放做语义终判）。不引入新的信任假设；唯一新增失败模式=host 重算实现缺陷（以 e12 式 native 对拍负例+受理门对拍双保险覆盖，见材料④）。

## 三、L2b 式行为锁双路径设计（distance 回退 legacy——②站 multilinear.rs 中继化同款）

**设计原则**（②站双路径先例逐条平移）：重排实施时电路**只保留新路径**（语句级重排无法双路径共存——循环物理删除），但**host 计算面保留双路径**：native 权威 `affine_mul_bits`（现役第五道防线）与受理门复算面**共用同一真值源**；行为锁=：

1. **宿主对拍锁**（现役同款，:1644「r·apk 循环输出 ≠ 宿主 [r]apk（语义级对账断裂）」）：重排后该断言从「电路循环输出 vs 宿主」变为「rk 实例钉值 vs 宿主 native 重算」——同式保留（装配面 assert_eq）；
2. **verify 侧复算锁**（新增，等价于 e12 ①′ native 重放的常驻化）：verify_instances/受理门对 rk 格==native [r]apk 复算对拍 fail-closed——负例=任意 rk 篡改必拒；
3. **C₂ 通道锁**：C₂ 完全加门对（Id·G, rk）的约束保持——e12 矩阵的 C₂ 加数篡改变体（c2rpk 格 mock）平移；
4. **距离回退语义**（L2b 先例的「distance≥4 回退 legacy」同精神）：重排的「回退面」=**FZ_ZK_REBASE_REMOVED=0 环境开关**——GO 后实施版保留原循环代码路径（编译期 feature 门控，缺省重排态），对拍/回滚/审计三用——这是比 ② 站运行期双路径更强的保险（语句级重排无法运行期切换，编译期双构型+同一 witness 对拍面承担等价性持续可证伪）。

## 四、Go/No-Go 预埋判据（与材料⑤联动）

1. 材料②判决 M1/M2 路线成立（−31.4% 实测）且密码评审通过 §一.1 三项语义变更审查；
2. 材料③ A/B 对拍全绿（双 OK+语义披露面完整）；
3. 材料④负例矩阵全绿（含新增 rk 复算锁）；
4. 材料⑤投入价值评估：prove 收益 ×1.15~1.3 [推得]（13,290/19,434 折算 sumcheck/装配承诺段——②站折算工艺）对回归成本（换代级联+第⑥次重部署+验签面复审）。
5. 任一不满足=维持不做（诚实留档，材料②的 gadget 否决判决与本表均入档为评审弹药）。
