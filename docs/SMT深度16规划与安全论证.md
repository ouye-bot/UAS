# SMT 深度 32→16（纪元轮换制）· 规划与安全论证

> 待办④交付物（2026-09-30）。结论先行：**论证为"不动电路"**——"约束减半"
> 的预期与实测结构不符（SMT 算术约束仅占全电路 1.3%），安全健全性虽与
> 深度无关但可用性边界劣化 65,536 倍需引入轮换机制，全链路换代成本
> （指纹+黄金向量+对拍锚+链上公示仪式）远超 4~8% 的 prove 收益，且演示
> 硬门已达标（服务器档 32.39s ≤ 60s，余量 1.86×）。以下为完整论证。

## 二、收益核算——"约束减半"预期被实测推翻

深度 32→16：路径 16 节点×2 块=32 组（组数减半）。按上表：

| 项 | 变化量 | 相对全电路 |
|---|---|---|
| 算术约束 | −128 | **−0.6%**（非减半） |
| advice 列 | −1,088 | **−10.6%** |
| lookup 通道 | −256 | −46.7%（lookup 面本身） |
| 环边 | 线性减半[估算] | 全电路环占比未细分 |

prove 时间模型（R1 归因表）：大头=列承诺（∝advice 列数）+外层
sumcheck（∝约束规模）+pcs_batch_open（∝开口对∝列）。列 −10.6%、约束
−0.6% ⟹ **prove 预估 −4~8% [估算]**（本机 75~90s → ~70~85s；服务器
32.39s → ~30~31s）。**演示故事线零变化**（"本机约 2 分钟"口径不变、
60s 硬门余量从 1.86× 到 ~1.95×）。

待办④"预计约束减半"的估算基础与实测不符——SMT 经 R2 查表门改造后是
"窄而密"形态（约束极少、列与 lookup 密集），深度减半省的是**列与环**，
不是约束。

## 三、安全论证（B3b-d1 框架延伸）

### 3.1 健全性：与深度无关（深 16 同样成立）✓

B3b-d1 拍板在案：**伪造非成员证明需要 SM3 碰撞（2^256 量级），与树深无关**
——攻击者要让"已吊销键 K 的伪造见证"通过电路验证，需构造 32/16 个兄弟
哈希链使重算根=公示根且叶层含 H(K)，即找到 SM3 原像/第二原像碰撞。R2 批
`weave_proto_gates` 已封堵见证重写空洞（伪造见证 61 行违约击穿[实测]）。
**深 16 不削弱健全性**。

### 3.2 可用性边界：碰撞概率劣化 65,536 倍（核心代价）

两撤销键前缀碰撞概率 P=C(N,2)/2^d（同前缀=同叶，插入歧义=RA 拒收/轮换）：

| 撤销集 N | 深 32 碰撞期望 | 深 16 碰撞期望 |
|---|---|---|
| 10 | 1.2×10⁻⁸ | 6.9×10⁻⁴ |
| 64 | 3.1×10⁻⁶ | **3.1%** |
| 256 | 2.0×10⁻³ | **39.7%** |
| 1000 | 1.2% | **≈7.6 个碰撞对（必碰）** |

- 深 32 在万级撤销集内碰撞都可忽略（可用性无忧）。
- 深 16 在 N≈64 时即有 3% 碰撞、N≥256 时近四成——**容量声明必须收窄到
  "每纪元 N≤~64"**，超出即触发轮换。

### 3.3 纪元轮换制分析（待办④拟议方案）

现有机制基础：撤销纪元已链上权威（revEpoch/revRoot，`ra/service.py:292`
链上纪元回读+`align_rev_root` 对齐仪式）。轮换制语义推演：

1. **旧键滚入义务**：撤销权威=最新公示根。轮换纪元时**全部历史撤销键必须
   滚入新树**——否则旧被吊销键在新根下"不在树中"=**撤销逃逸**（被吊销者
   重取见证即通过"未吊销"检查）。⟹ 纪元轮换**不解决容量累积**：新树仍装
   全量历史键，碰撞概率随 N_total 增长，轮换只是"重掷盐骰子"。
2. **盐轮换（可行解）**：树盐进叶哈希域分隔（`FZ-SMT-LEAF|salt|key`），
   碰撞时换盐全量重建+根更迭+链上 revEpoch++。同对键换盐后再碰撞概率
   1/2^16，k 次轮换后残余 1/2^(16k)——**渐近安全但每次轮换扰动面大**：
   在途见证全部失效重取、全量重算、公示根更迭。
3. **碰撞检测点**：RA 吊销/签发期（host 面预检——同前缀键拒收或触发轮换）。
   电路面 fail-closed（装配器无法生成合法见证，申请拒绝）——检测闭环成立。

结论：轮换制**密码学上成立**，但把"深 32 的静态余量"换成"动态运维仪式+
容量声明收窄+在途见证失效扰动"——演示语境下是负资产（演示要的是确定性）。

### 3.4 语义面

深 16=键前 16bit MSB。电路实例/承诺面（SMT 根钉在实例）不变；黄金向量
v4 的 SMT 见证槽 32 兄弟→16 兄弟——**实例布局换代 ⟹ canonical spec 换代
⟹ 黄金向量重生成 ⟹ Py↔Rust 对拍锚全部重钉**。

## 五、拍板（执行 AI 站在评委视角，按纪律记录理由）

**不动电路。** 理由：

1. "约束减半"预期被实测推翻（实际 −0.6% 约束/−10.6% 列/prove −4~8%
   [估算]）——收益不改变任何演示宣称与故事线；
2. 撤销电路是 R2 批刚加固的安全要害（伪造见证漏洞刚封堵）——为个位数
   百分点重动安全要害，违背"宣称-实现-文档三点一线"的稳定性纪律；
3. 演示硬门余量 1.86×，无性能焦虑；
4. 深度 16 必须引入轮换制/容量收窄——演示语境下增加不确定面；
5. 演示前窗口宝贵，1~2 天换代成本挤占演示准备（待办⑤）。
