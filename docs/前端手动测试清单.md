## 门户 http://localhost:5174（登录 / 飞手注册）

### ⓪ 飞手注册（两步向导）
| 步骤 | 预期结果（真实） |
|---|---|
| 「飞手注册」→填用户名+密码+确认密码→「生成密钥并建账户」 | 步骤 2 出现：账户已建立+**密钥指纹**（前 16 位）展示——钥对在浏览器生成、密码 KEK 密封后只上传密封件 |
| 注册页密码规则清单（实时勾选） | 至少 8 位/含字母/含数字/非常见弱密码/与用户名不同——五条实时 ✓/✗ |
| 负例：密码 <8 位或纯数字或 12345678 | 「密码未达标：<未满足项>」人话拒绝（不发起请求） |
| 负例：两次密码不一致 | 「两次密码不一致」 |
| 步骤 2 补资料（实名+无人机+机型类）→「提交资料并签发上链」 | **上链注册发生时刻**：主凭证签发+承诺哈希上链（成功卡显示哈希前 16 位）+「资料密文已存档——换设备登录自动恢复」 |
| 「进入飞证工作台」 | 进入「我的记录」（登记编号渲染） |
| 负例：已占用用户名 | 「用户名已被占用」（409 原样） |
| 密码统一口径 | 注册密码=登录密码=私钥解封密码=起飞前解锁密码——全程只记一个密码 |

### ⓪b 登录 / 登出

|---|---|

> （页面 5 秒自动轮询——审计员留守本页即可看到 admin 批准后的状态流转，
> 无需退出重登）。

|---|---|
| 审计员首次登录 | 初始密码（种子文件交付）→ 首登激活（当场生成审计员专属密钥）→进入审计台 |
