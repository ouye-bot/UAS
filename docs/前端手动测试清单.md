### ② 起飞申请
| 步骤 | 预期结果（真实） |
|---|---|
| 填计划（区域/用途/高度≤政策上限/时刻=现在以后）→ 密码解锁身份钥 →「提交申请」 | 六段真实进度（绑定→见证→证明→受理→核验→通过），证明段本机约 2 分钟 |

| **（新）六段刻度轨仪表化** | 提交后等待出证段：完成段实心 ✓+连接线点亮、当前段呼吸放大、未来段发丝圈；右下「已耗时」秒表持续走字（切页回来秒表连续不归零） |
| **（新）失败终态定格** | 出证失败→刻度轨当前段停止呼吸+红尾点、连接线退回暗轨——轨与错误盒说同一句话；重新提交后自动解除定格 |
| **（新）段编号单源** | 阶段标签不再带①~⑥圈号——编号唯一来自刻度轨数字（状态标签只说阶段事实不复读序号） |
| **（新）内存准入 429（条件触发）** | 仅当本机可用内存 <13GB 时提交出证→人话拒绝「本机当前可用内存 X.XGB 低于单张出证峰值需求约 13GB……请关闭内存占用后重试」——**正常内存演示不会触发**（防线目的=防双任务出证互卡拖垮整机） |
| **（新）凭证有效期核对 409（条件触发）** | 短效期凭证申请超过其有效期的授权窗→「凭证有效期不覆盖申请的授权窗——请重新登记后申请」（409 `cred_expired_window`）——**正常流触不到**（子凭证 24h 有效期 > 政策窗上限 6h） |
| **（新）绑定面限速 429** | 同一 IP 一分钟内对出证提交面连打 >30 次→「请求过于频繁（每 IP 每分钟 30 次）——请稍后重试」；窗口过后自动恢复 |
