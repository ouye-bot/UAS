## 二、TCB 边界（诚实声明——生产形态下的残余信任）

1. **固件围栏**：地面站/桥接可被用户绕过（TCB 第①层）；固件围栏=第②层硬强制
   （S2 实锤：32.39m 触发硬拦截）。真机形态下固件层由设备厂商签名的固件承担。
2. **设备钥**：demo=桥接进程模拟（D16 声明）；生产=SE/TCM 硬件根。签名验证逻辑
   两态一致——验证方可离线复验（检查点报文公开）。
3. **授权服务正确性**：「先验证后签发」依赖服务实现正确，由**可审计签发**背书
   （proofDigest 上链+判决件三件套归档+第三方复验——作弊必然可检出）。
4. **链**：联盟链准入由机构证书控制；链上不留身份（D18）——追溯=令状+RA 协作双控。

## 账户批部署注记（2026-09-30）

- **/auth/* 限速器为进程内存固定窗**（app/accounts/service.AttemptLimiter）——
  单进程演示形态有效；多进程/多实例部署须换共享存储（Redis/PG）后端，否则
  窗口按进程分叉、攻击者可横向稀释限速。列部署检查项。
- **会话 Cookie**：HttpOnly+SameSite=Lax；生产 TLS 部署须置 Secure（router
  内注释开关位）。跨站前后端（域名不同）须 SameSite=None+Secure+CSRF 防护
  ——当前同站对齐方案仅适用环回/同域部署。
- **双控后台执行**：单进程内存线程+启动恢复（approved 残留→execute_failed）。
  多副本部署须任务表租约（参考 authz worker 的 locked_by/locked_at 语义）。
