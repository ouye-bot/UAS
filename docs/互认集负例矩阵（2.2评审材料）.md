# 互认集负例矩阵（2.2 二期评审材料③）

- **性质**：互认集成员证明进电路（材料①设计）的**验收红线**——三类任务书点名负例（非互认根/过期锚/退出机构根）+ 电路面负例扩展。每条钉：攻击形态/拒绝始终/实现层/测试形态。工艺全部有现役先例锚（R2 加固实弹检验过的 SMT 负例族+⑥一期链面负例族平移），零新发明。
- **分层拒绝原则**：负例在**能拒的最早层**拒绝——装配面（结构非法）→ 电路面（证明不成立）→ 受理门（与链面不一致）→ 链面（非权威写者）。跨层冗余是特性不是缺陷（单层失陷不连锁）。
- **实验形态声明**：本矩阵是二期**实施时**的验收红线（实施=T1/T2/T3 触发后）；2.2 批只交付设计与实测，不实施负例代码。实验分支 `exp/2.2-mutual-smt-census` 的织入实现使电路面负例（§四）在分支内可验证。

## 一、任务书三类负例（受理门+链面）

### N1 非互认根（伪造互认集根）

| 维 | 内容 |
|---|---|
| 攻击形态 | 攻击者（非 governor）自设一棵互认集树（把自选机构集/自选锚叶聚合成根），试图让受理门/第三方按其根验证明——「我的机构在互认集内」 |
| 拒绝始终·链面 | `setMutualRoot` **onlyGovernor**（时间锁仪式）——非 governor 直调 revert（与 AdminGovernor 既有治理面同构：治理自身函数 only msg.sender==address(this)，owner 直调也拒——③站工艺）；时间锁窗内可监测 |
| 拒绝始终·受理门 | 实例 27 == 链上 `FedRegistry.mutualRoot()` 对拍 fail-closed（409 `stale_mutual_root` 同族）：攻击者即使出了一证（钉了自选根），受理门回读链面权威根不相等 ⟹ 拒 |
| 拒绝始终·第三方 | pin 换代后第三方凭链面 mutualRoot 复验——伪根不在链面公示 ⟹ 复验拒绝（无受理门可绕） |
| 测试形态 | 链烟：非 governor 调 setMutualRoot revert + governor 仪式后回读对拍；受理门面：篡改实例 27（或用伪根出证）⟹ 409 |

### N2 过期锚（stale 互认集快照）

| 维 | 内容 |
|---|---|
| 攻击形态 | 申请者持**旧互认集快照**的见证出证（旧根=旧机构集合/旧锚纪元——例如退出机构在旧快照中仍在集内，或新准入机构未进快照），试图让受理门按旧资格面放行 |
| 拒绝始终·受理门 | 实例 27（证明钉的根）== 链上当前 mutualRoot 不等 ⟹ 409 `stale_mutual_root`（fail-closed 强制刷新——现役 `stale_rev_root` 门控同构工艺：A6）；**同时** worker 见证新鲜度门控（mutualEpoch 对齐）在见证生成侧就拒发旧快照见证——双门 |
| 拒绝始终·电路面 | 无独立拒绝（根是公开实例——证明数学上自洽）；过期性是**与链面状态的关系**，电路不管——这正确：电路证明「叶∈根」，新旧都是合法的数学事实；新旧取舍=受理门对拍链面权威 |
| 测试形态 | 受理门面：governor 更新互认集根后用旧快照见证申请 ⟹ 409；刷新见证后重放 ⟹ 放行（幂等正例对照）；worker 面：mutualEpoch 落后 ⟹ 见证生成拒绝 |

### N3 退出机构根（retired 机构锚残留）

| 维 | 内容 |
|---|---|
| 攻击形态 | 已退出机构（retired，⑥一期锚冻结语义）试图：(a) 用退出前锚的叶路径继续出证（旧互认集根仍含其叶）；(b) 伪造「仍在互认集内」的成员证明 |
| 拒绝始终·链面 | 退出流程=governor 仪式重算互认集根（剔除 retired 叶）⟹ 链面权威根不再包含该叶；叶冻结（锚停更）但根已换代 ⟹ 旧叶路径对新根的证明在数学上不成立（旧路径重算出旧根≠新根） |
| 拒绝始终·受理门 | 双重：①资格对拍——`orgs[orgId].retired==true` ⟹ 422/403（⑥一期 unknown_org/retired 语义延伸，先例 chain_smoke §⑨-c 三类负例）；②根对拍——旧根≠链面当前根 ⟹ 409（N2 同门兜底） |
| 拒绝始终·第三方 | 复验用当前链面 mutualRoot——旧根证明拒绝 |
| 测试形态 | 链烟：退出仪式（叶剔除重算+新根公示）后：旧根出证 ⟹ 409；retired org 直调锚推根 ⟹ revert（⑥一期既有）；受理门：retired org 申请 ⟹ 422 |

**N3 与现役撤销负例的关键差**：撤销树（深度 32）的默认空树形态天然支持非成员验证（EMPTY 叶链）；互认集树（深度 6 满树）**只有成员验证方向**——「retired 机构不在集内」的证明=新根中该叶位为空叶摘要（DEFAULT 叶）的成员证明（退出仪式把叶重置为空叶摘要再公示新根）——语义在叶重置动作，不在电路方向。设计钉死：退出仪式=「叶置空+根重算+governor 公示」三步（材料① §四.2）。

## 二、电路面负例（扩展——SMT 负例族平移，vacuity 红线工艺）

### N4 假根折叠（装配/证明面）

- **形态**：见证的路径/兄弟被改写使链终点≠钉根（伪造成员路径）。
- **拒绝**：根折叠约束（Σ2^{32k}·(Σ2^{4j}·shadow)==实例 27）——链终点摘要词经复制环到影子列，影子折叠必须等于公开实例值；改路径 ⟹ 终点变 ⟹ 折叠违约 ⟹ 证明不成立（verify 拒）。
- **测试**：`mutual_forged_root_vacuity_red`（平移现役 `auth_smt_forged_root_vacuity_red`——假兄弟+真根的环类改写攻击必须被拒，vacuity 断言=改错后约束违约非静默通过）。

### N5 路径位洗白（bit 位伪造）

- **形态**：路径位格不被电路消费 ⟹ 证明者可逐位选边拼任意叶进根（洗白通道——现役 SMT dump 定谳前的假绿源）。
- **拒绝**：三重工艺平移——①路径位 bool 约束（6 bit 格∈{0,1}）；②recomb（Σ2^g·bit_g==键锚格值——形态 A=装配期常量，形态 B=orgId 派生词格）；③mux 每块 2 条（msg 由 bit 在 cur/sib 间选边——bit 进约束=被电路消费）。选择器无激活点=约束真空=封堵失效（dump 定谳教训）——**选择器激活点断言**入负例测试。
- **测试**：`mutual_bit_flip_vacuity_red`（任意一位翻转 ⟹ 链断 ⟹ 拒）+选择器激活点非空断言。

### N6 叶值自由度（成员叶起链/任意叶）

- **形态**：形态 A 下叶摘要（cur_0）是自由见证——证明者可声称「任意叶∈根」？**不能**：根钉锁死消息自由度（SM3 抗碰撞——给定根与路径，叶被函数式锁定；随机叶使链终点≠根 ⟹ 折叠违约）。但「叶=锚摘要」的业务绑定（叶确实是某机构的 orgId‖epoch‖root 摘要）**不在电路内**（形态 A）——攻击者可以证明「某随机 32B 值∈根」（数学真）但业务上无意义（该值不对应任何机构锚——链面锚公示叶对拍拒绝其受理）。
- **拒绝**：受理门/链面对拍叶摘要==SM3(orgId‖epoch‖root)（FedRegistry 锚公示面重算）；形态 B 升格为电路内绑定（叶原像词格+压缩+root==实例 23 等值）。
- **测试**：链烟：锚公示叶对拍断言；形态 B 实施时加 `mutual_leaf_binding_vacuity_red`（叶原像 root 字段≠实例 23 ⟹ 拒）。

### N7 容量与键位（第 65 机构/键位冲突）

- **形态**：深度 6 满树容量 64——第 65 机构准入；或两机构键位冲突（orgId 低 6bit 同值——orgId 递增分配下 64 内不冲突，属断言面）。
- **拒绝**：登记面（FedRegistry registerOrg 容量断言 orgId<64 revert）+装配面断言（键位==叶位）。
- **测试**：链烟：第 65 registerOrg revert；装配：键位与叶位不一致 ⟹ 拒。

## 四、验收红线声明（二期实施时）

1. 上述 N1~N7 全部落地为**自动化断言**（链烟 §⑩-m 扩展族+受理门面负例+vend or vacuity 红线）后才算实施完成；vacuity 红线纪律=「改错必须违约」非「改错不报错」（dump 定谳教训：假绿=选择器真空）。
2. 三类任务书负例（N1/N2/N3）是**受理门+链面**验收红线；电路面负例（N4~N6）是**证明健全性**红线；两类并集才是二期验收面。
3. 任何一条负例在实施中被「放松判据」绕过=纪律红线事件（复评 §1.2 的锚 root 零校验先例——FedRegistry.sol:63-73 任意 32B 可锚的教训在案：**锚的语义安全不得寄生于「不被消费」**，二期互认集根进受理判词后必须配 root 结构校验（mutualRoot 只能经 governor 仪式写入=结构上封堵））。
