# ⑧变基窗化重申评审材料③：同见证双二进制 A/B 对拍方案设计

- **性质**：GO 后实施批的验收工艺设计（本批只制备）。基线工艺=②站零语义双实锤（同见证同电路双二进制 proof 逐字节同+26 实例逐位同——中继化/调用级并行批）与 2.1 批 A/B 对拍（同二进制双通道钉盐世界三件 cmp 同+跨二进制三方同）。
- **🔴 关键差异声明**：⑧是**语句级重排**（材料①命题 R）——电路结构变（E10 循环出电路+实例面 26→28）⟹ **proof 不可能逐字节同**（电路不同 ⟹ 指纹不同 ⟹ 转录不同）。A/B 对拍的判决对象=「**同见证下双语句各自自洽+验证语义等价**」，工艺从「逐字节同」降格为「**双 OK+结构对拍+语义对拍三层**」——本材料把三层钉死，防止实施批用「逐字节同」的旧锚硬套产生假绿或假红。

## 一、对拍三层设计

### 第二层：双 OK 对拍（prove/verify 闭环，同见证双二进制）

- **同见证**：canonical spec（黄金向量见证源）+同一 `FZ_ZK_SALT_PIN=1 MASK_OFF=1` 差分世界（2.1 批工艺——钉盐+掩蔽关=全证明路径零随机源 ⟹ 各自二进制内跨次可复现，跨二进制间对拍为语义级非字节级）。
- **判据**：A/B 各自 `zkc prove` OK（盘上回读 verify OK）；A/B 的 **instances.json 逐位同**（公开实例面=语句公共语义——rk 新增 2 项除外：B 侧 28 项 vs A 侧 26 项，前 26 项逐位同+后 2 项==host [r]apk native 重算值）；verifier_param 尺寸/结构对拍（+2 实例行≈+96B 量级 [推得]）。
- **A/B 表**（工艺同 2.2 材料② §二）：proof 尺寸/prove_s/verify_s/total_s 双列+Δ——安静窗纪律（LoadPercentage 确认+无并发重载进程）。

### 第三层：语义对拍（验证语义等价——材料①命题 R 的运行时实证）

1. **rk 复算对拍**：B 侧 instances 的 rk.x/rk.y == host `affine_mul_bits(&r_bits, apk)` [实测锚=现役装配断言同款]——负例=篡改 rk 任一坐标 ⟹ 受理门/verify_instances 复算拒（材料④ N1）；
2. **C₂ 通道对拍**：C₂.x/C₂.y 实例（现役 14/15）双侧同值——B 侧的 C₂=Id·G+rk（rk=输入格）与 A 侧 C₂=Id·G+[r]apk（rk=循环输出）——**同见证下 C₂ 实例值必须逐位同**（等价性的直接运行时证据）；
3. **native 重放锁**：e 摘要词 mock 后 native 四步重放失败（e12 ①′ 同款）双侧行为一致。

## 二、对拍执行清单（GO 后实施批的验收序）

1. 双二进制构建（A=现役 pin 基线 zkc / B=重排分支 zkc——各自 repin）；
2. census 双跑（diag_dead_cols+tally stdout 逐段对账——第一层表逐行填实）；
3. 同见证双 OK（第二层——SALT_PIN 世界+生产构型各一发）；
4. instances 逐位对拍（前 26 项同+rk 两项==native 复算）；
5. C₂ 通道同值断言（第三层.2）；
6. A/B 表落性能档案+负例矩阵全绿（材料④）+全量回归（换代级联按复评 §4 清单——实施批范围）。
