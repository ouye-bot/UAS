# 落地实用化改进路线（2026-09-21，队长纪律修正后重构）

> **纪律修正（队长 2026-09-21 指示）**：系统不是演示 demo 玩具——功能可以少，但每一个
> 都要成熟、高度专业化、真正具备落地实用性。一切功能设计与前端设计从**实用、专业**的
> 角度出发，而不是演示方便、看起来好看。占位/替身/Fake 只允许存在于 CI 测试面；
> **产品面出现占位材料、断链流程、假状态即缺陷**。
>
> 本路线以此为唯一准绳，把此前对话中的全部缺口重组成工程路线。

## 零、产品定义（DoD 总纲）

**一个全新飞手，在无工程师协助下，30 分钟内完成：登记 → 申请（本机实时出证）→
服务端验证通过 → 取件 → 解锁起飞（真 SITL 围栏）→ 飞行采样 → 生成合规证明 →
（事件化场景）审计令状真链追溯。全程真实链、真实证明、密钥不出设备（抓包可证）。**

每项工作的验收=上述用户旅程中的一段可以独立、可重试、失败有明确原因地走通。

## R1 实用化主线（当前批次——把"三条失败路径"变成真实通路）

### R1-1 桥接实时出证服务（核心——隐私架构的产品化）
- **架构原则**：见证（身份证号/盐/私钥）不出设备。出证发生在飞手侧桥接进程
  （透明 SNARK=无需可信设置，飞手本地 prove 是其自身计算），只有证明+公开结论
  提交服务端。服务端 worker 只做验证（3.5s）。
- **接口**（`gcs/bridge/prover.py` 新增，`server.py` 挂载）：
  - `POST /prove/start`：入参=申请参数（计划、高度、机型类）+ 本机登记材料
    （登记库自动取：盐/子凭证/持有者钥）→ 组装 JobSpec（含服务端公示的绑定值
    challenge/pred_id/t_epoch/required_level）→ 临时文件落盘 → 子进程 `zkc prove`
  - `GET /prove/task/{id}`：状态机 assembling→proving→done/failed + 结果路径；
    失败含可读原因
  - 安全：材料临时文件用后即删；日志零秘密；任务目录权限收紧
- **验收**：任一新用户提交申请→桥接本地出证成功（AUTH 本机 ~115s [实测基线]）→
  提交后端→worker 真实验证 approved→回执 ready。全程无预生成、无占位。

### R1-2 申请屏接实时出证（前端）
- 申请提交改为：先调桥接 `/prove/start` → 进度条绑定真实任务状态
  （组装/证明中/完成）→ 出证完成自动提交后端受理 → 回执等待（worker 秒级）→ ready。
- 等待期文案承载真实进度（"正在本机生成零知识证明…约 2 分钟"），不伪造速度。

### R1-3 链上化默认（fake 降级为 CI 专用）
- 演示/产品运行默认 `FZ_CHAIN_ANCHOR=真链`：登记上链、授权登记+proofDigest 上链、
  检查点锚定、令状——全部真实（烟测 50 断言+S4 17 断言已是真链判决行）。
- fake 模式保留于 pytest/CI；`demo_up` 默认真链（WSL 链拉起并入脚本）。

### R1-4 SITL 真接线（web 飞行屏 → 真飞控）
- bridge 增 `--sitl` 运行模式（`SITLLink` 替换 `FakeLink`，单会话拉起纪律——B5 已验证）
- web 飞行屏：解锁=真令牌核验+围栏参数写入真飞控；采样=真 MAVLink 遥测流（2Hz）；
  越限=固件 STATUSTEXT 事件捕获。替身链路仅保留单元测试。
- **验收**：S2 形态在 web 面复现——前端点解锁→RC 爬升→围栏触发→事件上链可见。

### R1-5 链上留痕可视化（前端治理面板）
- 顶栏/侧栏：区块高、我的登记交易、授权记录（authId/proofDigest/状态）、
  锚定检查点列表、（审计台）令状交易——数据全部链上回读。
- 这是"区块链如何应用"的产品面答案：留痕看得见、可核验。

### R1-6 TRAIL 合规证明闭环
- 报告数据导出→出证（TRAIL n=128 服务器 14.77s/本机数分钟）→**合规证明判决件
  下载**（proof/verdict/param 三件套）——飞手最终拿到可第三方复验的合规证书，
  而非一个 JSON。

## R2 安全与运维加固（生产级成熟度）

| 项 | 现状（诚实） | 生产形态 |
|---|---|---|
| 服务间传输 | 本机 HTTP | mTLS（后端三服务+桥接互认） |
| 服务端密钥 | 进程内域派生（演示） | KMS/HMS 抽象层：Provider 接口（demo=软件派生，生产=HSM 实现），密钥轮换程序 |
| 用户会话钥 | sessionStorage（已焚化） | WebCrypto 非导出密钥/系统密钥库封装 |
| 设备钥 | 桥接进程模拟（D16 TCB 声明） | 伴飞计算机+SE/TCM 芯片（落地路线成文） |
| 数据库 | SQLite | PostgreSQL 迁移（SQLAlchemy 已抽象+alembic 兼容） |
| 任务队列 | DB 状态机轮询 | 持久化队列：crash 恢复/重试/幂等（proof 指纹去重） |
| 进程治理 | 手工/脚本拉起 | Windows 服务（NSSM）/WSL systemd：守护+日志+健康检查 |
| 认证 | 审计台单令牌 | 密钥证书化+操作审计链 |
