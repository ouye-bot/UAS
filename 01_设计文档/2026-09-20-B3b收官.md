## 一、语句级安全论证（硬验收门：R_AUTH ⑥ SMT 构件归约）

### 1.1 R_AUTH 增补构件（B3 收官 §1.1 的 ⑥ 项落地）

```
⑥ 主凭证不在撤销累加器中（SMT 非成员）：
   公开输入增：rev_root（实例 23=词序折叠口径 fold_words_be）
   私密见证增：32 层兄弟子树根（叶→根序）、路径位（键=pk′.x 前 32bit MSB）
   关系：
     cur_0 == EMPTY（=SM3(b"FZ-SMT-EMPTY")，预处理列电路强制——非见证）
     ∀g∈[0,32): (msgL_g − cur_g) − bit_g·(sib_g − cur_g) == 0   （左半 mux）
                 (msgR_g − sib_g) + bit_g·(sib_g − cur_g) == 0   （右半 mux）
                 其中 msg_g = SM3 标准消息（cur_g‖sib_g 或 sib_g‖cur_g 按 bit_g）
     cur_{g+1} == SM3(64B 块 g)（数据块+padding 块链式双压缩——与 smt.py 同构）
     Σ2^{31−g}·bit_g == pk′.x 词 0（路径位↔出示公钥绑定）
     fold(链头) == rev_root（实例钉）
```

### 1.2 健全性归约（SMT 构件）

| 构件 | 电路强制 | 归约 |
|---|---|---|
| 非成员起点 | EMPTY 预处理列（**非 advice**——成员叶起链攻击的封堵点） | 伪造起点+自选兄弟 ⟹ 链头≠rev_root 需 SM3 抗原像 |
| 内节点哈希 | 双块链式（数据块 fresh IV+padding 块链 IV——复制环强制） | SM3 抗碰撞：改任何中间值 ⟹ 链头变 ⟹ 根钉拒 |
| cur 链式 | cur lane 环桥上块摘要 cells（环=等值类跨行） | cur 非自由值——链 soundness 电路内强制 |
| 路径位绑定 | 32 bit 格 bool+recomb==pk′.x 词 0（pkx 被 E8 [sk′]G=pk′ 绑定） | 洗白封堵：路径位=自己出示公钥的位（换位 ⟹ recomb 违约） |
| bit 全行等值 | bit lane 128 行同值播种+全行环桥（块内 limb 行分布） | bit 逐行伪造通道闭合（环=跨行等值类标准解） |
| 根钉 | fold 实例 23（系数 f_pow2 权威派生） | 任何 (兄弟,位,起点) 组合 ⟹ 重算根必须=链上公示 rev_root |
