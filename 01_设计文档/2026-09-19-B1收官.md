## 四、执行期问题与根因（全部当场定谳修复）

| 问题 | 根因 | 修复 |
|---|---|---|
| wsl.exe 传中文路径损坏编码 | wsl.exe 参数层编码转换 | cwd 继承形态（`wsl bash script.sh` 不传路径） |
| wsl bash -c 内 `$VAR` 被吃 | 同上参数层 | WSL 侧逻辑落盘 compile_wsl.sh |
| `--bin-runtime` 输出名≠`.bin` | solc 0.4.25 实际输出 `.bin-runtime` | 探针定谳后修正 mv |
| mapping(string=>X) 编译崩 | 0.4.25 无动态 key 访问器 | B1-d7 bytes32 键 |
| call 零地址 from 静默 | 已知坑（旧系统事实#1） | ChainClient(from_addr=) |
| getCode 参数形态 | 需带 groupId | [group_id, addr] |
| wait_receipt 拦截负例回执 | 正例保护与负例冲突 | expect_revert 原始轮询 |
| 冷启动 seq=1 断言写反 | seq=1 本合法（0+1） | 改测跳号 seq=2 revert |
| TxSigner.address 是 property | 方法调用 TypeError | 全量 `.address()`→`.address` |

**环境教训（入 MEMORY）**：① wsl.exe 从 Git Bash 传参（中文/`$`/引号）多层损坏——WSL 侧逻辑一律落盘脚本+cwd 继承；② 管道会吃退出码（`cmd | tail; echo $?`=tail 的码）——判决行验证禁接管道；③ grep 过滤分段输出会截断误判。
