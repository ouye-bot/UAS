# B7 审计台+令状追溯 · 实施计划（TDD 任务级）

> 批次：B7（框架 §7.4/§十）。验收门：**追溯判决行（事件→个人全链留痕）；
> 无令状解锁=拒绝负例**。对照六问 A3（消费 B4 已落通道②端点）。

**Goal:** 令状追溯闭环——审计台创建令状（案号+scope+法律依据哈希）→上链
WarrantLog（onlyAuditor）→RA 协作解锁（消费 A3 通道②：unwrap 实名映射）→
解锁留痕上链（logWarrantUnlock）→审计台展示实名关联与全部留痕（链上回读）。
审计员密钥认证（无口令体系）；令状不可撤销只能追加。

**架构决策（B7-d1~d3，执行期拍板）：**
- B7-d1：解锁留痕=合约新增 `logWarrantUnlock(bytes32,bytes32) onlyRA`
  （require 令状在案+一次性）——B4 服务面已按此名调用（anchor 回调），
  本批补齐合约面+烟测断言。**否决**复用 logWarrant（require 一次性语义冲突）。
- B7-d2：审计台=backend 单体挂 `/audit` 路由+**后端直出单屏静态页**（vanilla
  JS，无构建链——治理面非用户面，不进 gcs/web Vue 栈）。认证=X-Audit-Token
  （KMS 审计域派生 token，等值比较——无口令体系，密钥即身份）。
- B7-d3：追溯视图=warrant+解锁结果+**链上留痕回读**（FlightAuthRegistry.getAuth
  /TelemetryAnchor 检查点与事件 by authId）——链是留痕单一事实源，DB 只存
  令状登记面（案号/法律依据哈希/解锁结果审计行）。

**Tech Stack:** FastAPI+SQLAlchemy（audit 表随 alembic 0002 迁移）、四合约
（IdentityRegistry 增面）、vanilla JS 单屏。

## 任务分解（TDD）

### T1 合约增面（红→绿）
1. 红：`chain_smoke.py` 增断言组「logWarrantUnlock」（RA 解锁留痕上链+
   warrantUnlocks 回读 true+非 RA revert+未在案令状 revert）——先跑=编译期
   ABI 无此函数（ValueError）即红。
2. `contracts/src/IdentityRegistry.sol` 增：
   ```solidity
   event WarrantUnlockLogged(bytes32 indexed warrantHash, bytes32 credHash, address ra, uint64 ts);
   mapping(bytes32 => bool) public warrantUnlocks;
   function logWarrantUnlock(bytes32 warrantHash, bytes32 credHash) external onlyRA {
       require(warrants[warrantHash], "warrant not on file");
       require(!warrantUnlocks[warrantHash], "unlock already logged");
       warrantUnlocks[warrantHash] = true;
       emit WarrantUnlockLogged(warrantHash, credHash, msg.sender, uint64(now));
   }
   ```
3. `bash contracts/compile.sh`（WSL solc 重编译+manifest 换代）→
   `chain_smoke.py --deploy`（重部署+地址换代+权限接线+全自检）→幂等二轮。
4. 判决行：烟测 46+4=50 项断言全绿 exit 0。
