### 批 5 · 队长实测反馈两轮根修（f900956/15dde93/批 5c）
- **爬升/自动飞行不动根因**：fz-sitl 重启未加 `-w` ⟹ eeprom 残留 RTL 模式
  （RC override 在自主模式无效）+ **SITL 流死**（TCP 半开连接阻塞飞控主
  循环——8s 0 消息 [实测]）。修复：`-w` 干净重启+ARM 成功即强制
  STABILIZE+采样响应加飞控模式旁路+前端非 STABILIZE 黄条警示；
- **解锁慢**：set_param 确认丢失 3×4s 全额等待→0.5s 周期重发（12s 总窗）；
- **TRAIL 404**：前端调用路径错（/trail/start vs /prove/trail/start）——
  浏览器真实调用与接口 e2e 脱节又一案例；全站调用路径审计（其余对齐）；
- **SITL 流死统一修复**：global_position/drain 全收分类（消除 recv_match
  type 过滤丢弃同流 ATTITUDE/HEARTBEAT 的旁路概率性丢失）。

### 尾修 · demo_up WSL 桥启动（2417fe9/69f4b81）
- **junction 双形态根修**：junction 作 FZ_ZK_CASES_DIR ⟹ wslpath -w 对

  `D:\Meeting_Archive\_fz_bridge_start.sh`（纯 ASCII）后 wsl bash 执行；
- **桥守护化**：`fz-bridge` systemd 瞬态单元（--uid=ouye+exec 前台）——
  根除 WSL nohup 进程被会话清理清杀的反复死亡。

### 批 6 · 队长实测第二批根修（2026-09-28 凌晨，b6d4408+280c09f）

- **3D 黑屏（跟随/俯视）**：FlightView 样本键名 lat/lon 与 FlightGlobe 期望
  lat_1e7/lon_1e7 错位 → NaN 传播至两视角相机（环绕相机不依赖 disp 幸存
  ——「部分视角坏」=数据 NaN 指纹）。修=键名统一+SampleRow 类型化（any
  数组曾杀死 tsc——类型化后当场抓出漏改 3 处）；
- **「悬停落地」破案**：ArduPilot **静默忽略 MAVLink SET_MODE 消息**（SERIAL1
  嗅探实锤——无 ACK 无 STATUSTEXT 无效果；批5c「强制 STABILIZE」实为
  eeprom 默认值掩盖的假象）。STABILIZE 无定高回路，中立油门=缓降，「悬停」
  必然落地。修=模式切换走 MAV_CMD_DO_SET_MODE(176) command_long+ACK/
  HEARTBEAT 双确认+指令前自动切入 ALT_HOLD（油门杆=升降率）；
- **控制语义重设计**：手动/定高悬停/自动飞行三源互斥状态机+「飞行控制」
  chip+到达目标自动转悬停+ARM 前置 STABILIZE 预切换（RTL not armable
  根治）+fc_armed 旁路红色横幅（地面怠速自动上锁=重解锁指引，同会话
  重解锁不烧授权）；
- **TRAIL「出证中」双层根因**：(a) Windows zkc 写↔WSL 桥读 9p 可见性窗口
  非确定（实测 0.1s~6s+）——done 语义=真读回自证+端点内 ENOENT 短重试+
  TrailView「重新获取判决件」（案卷持久归档，无需重新出证）；(b) SITL 地面
  相对高度抖动为负（-1cm）→ 窗口行 u16 打包越界 500——记录面归一；
- **审计台**：随案协作函获取程序说明（登记机构出具=双控第二因素）+no-cache；
- **前端文案风格整改**：链上留痕四板块客观权威化（去对话式解释——解释性
  内容归内部文档）。

## 三、架构决策记录

1. **旁路字段架构**：链=合规证明面（最小 14B 行），UI=态势面（姿态/航向/
   爬升率/模式旁路）——审计叙事不变，两面向各自演进；
2. **绑定面差异判据**：有无方程锚定决定绑定面形态——C₁/Id·G 无方程锚定
   ⟹ 必须绑定环+recomp；eg 的 s_g 被验签方程唯一锚定 ⟹ 免绑定环；
3. **合成采样分档**：产品 demo_up 档物理关闭 / 判决脚本档显式开启——
   「测试面可用 ≠ 产品路径可入」隔离范式；
4. **WSL 桥 ASCII 脚本范式**：wsl.exe 只传纯 ASCII 脚本路径，中文真实
   路径全在脚本内容内（UTF-8 WSL 侧读取零乱码）。
