# B3 AUTH 电路 · 收官文档（2026-09-20）

## 一、语句级安全论证（硬验收门：关系形式化+健全性结构+信任假设）

### 1.1 关系形式化定义 R_AUTH

**公开语句 x** =（pk_RA, sn_h, plan_hash, nonce, policy_version, required_level, t_epoch, id′·G 压缩编码, exp_u, C, ctx_tag, pred_id）

**见证 w** =（salt, id_number, cert_level, sk′, r_s, s_s；B3b 追加：SMT 非成员路径）

**关系**：

```
R_AUTH = { (x, w) :
  ① C == SM3( salt ‖ cert_be4 ‖ id_number ‖ sn_h )                    （承诺原像，54B 单块）
  ② Verify_SM2( pk_RA, fold(SM3(M_A)) , (r_s,s_s) ) == 1              （RA 子凭证签名，电路口径 e=词序小端折叠）
     其中 M_A = Z_A(pk_RA) ‖ x(id′·G) ‖ C ‖ pk′.x ‖ pk′.y ‖ exp_u ‖ par
  ③ cert_level ≥ required_level                                        （u32 范围门，δ=recomb 消费式钉）
  ④ exp_u ≥ t_epoch                                                    （S6 有效期谓词，32 位分解无溢出）
  ⑤ ctx_tag/pred_id 与申请绑定                                         （T2.5 消费式实例钉；plan_hash/nonce/
                                                                         policy_version 服务层复合折算——B3-d8）
  （B3b 追加 ⑥：主凭证句柄不在撤销累加器——SMT 非成员）
}
```

**知识声明**：证明者知道 w 使 (x,w)∈R_AUTH。零知识性：id_number/salt/cert_level/sk′ 仅为电路内 witness 列，公开面（实例向量 23 槽）经探针差分核验不含任何原像位。

### 1.2 健全性结构（逐构件归约）

| 构件 | 电路强制 | 健全性归约 |
|---|---|---|
| M_A 重建+SM3 三块链 | 查表化 SM3（SM3_LUT=1 部署默认；查表=4 约束/块+通道行） | SM3 抗原像性：伪造 M_A′≠M_A 使同 e 概率 ≤2^-256（查表完备性=引理 D+logUp 覆盖声明，本团队论文线已采纳） |
| e 词序折叠 | E7 大折叠 Σ2^{32k}·dgw_k == pv@row_ae（复制环） | 域算术恒等式——折叠系数 f_pow2 权威派生禁手抄 |
| SM2 验签 | (S2) 验签体 16,554 约束（E8-E10：[sk′]G 循环/双承诺 C₁,C₂/完全加 apk） | ECC 离散对数+SM2 验签方程：(e+x₁)≡r (mod n) 伪造 ⟹ 解 ECDDLP 或找 SM2 方程碰撞 |
| C 原像绑定 | (S7) CommitOne 单块（54B 消息根表）+C 环（z 出口⟷M 槽词） | SM3 抗原像+复制环等值（一格一环不变量） |
| cert≥required | δ×32 位 bool+recomb：Σ2^i·δ_i−cert+θ(inst22)=0（q_inst 消费式） | 位分解唯一性：违约见证在某 i 位非 0/1（bool 捕获）或重组≠cert−θ（线性捕获）；θ 篮改=实例消费违约（T2.5 机制） |
| exp_u≥t_epoch | S6：32 d 位 bool+Σ2^{31−p}·d_p−exp+T(inst21)=0 | 同上（T2.6 既有 gadget，f667c11 定谳形态） |
| 绑定 | T2.5：ctx/pred_id 钉列+emit_pin_val_only 实例 19/20 | 实例钉=公开面绑定——伪造者不能改申请参数而不改公开语句（改了即验证方拒） |
| 持有者绑定 | apk=pk′+pk_RA 聚合+sk′∈[1,n−1]（bool+lt_n+neq_zero） | 证明者须知道 sk′ 使 [sk′]G=pk′——一次性子凭证私钥不出端侧的电路内强制 |
