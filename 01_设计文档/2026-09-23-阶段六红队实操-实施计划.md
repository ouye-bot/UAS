# 阶段六 红队实操——实施计划（2026-09-23）

> 目标：以攻击者视角对**运行系统**实操验证防御，产出攻击记录。
> 纪律：得手=当场根治再回归；未遂=记录为答辩武器；边界=显式声明不装没看见。

## 攻击矩阵（10+1 项）

| # | 攻击 | 手段 | 预期防御 |
|---|---|---|---|
| A1 | 回执码穷举 | 随机 128bit 码×5 查询 | 404（2^128 空间） |
| A2 | ECIES 密文比特翻转 | 翻转令牌密文 1 字节后取件 | 解密必败 |
| A3 | 假证明注入 | 垃圾 proof.bin+合法形态 instances → 受理 → worker | zkc verify 拒→回执 failed |
| A4 | 受理实例篡改 | 同 case 提交 t_start+1 | 409 instance_mismatch |
| A5 | 时间窗滥用 | t_end=起点+24h（超 6h 政策窗） | 409 window_too_long |
| A6 | 接口灌爆 | 443 keep-alive 30 连发 apply | 429（限流） |
| A7 | 跨角色越权 | attacker 钥调 registerCommitment/logWarrant/publishPolicy | 链级 revert ×3 |
| A8 | 审计台越权 | 错 X-Audit-Token | 401 |
| A9 | nonce 重放 | 同 nonce 二次受理 | 409 nonce_used（链级） |
| A10 | 钥密文/承诺穷举 | keystore 篡改+计划同文异盐（引用型：web 测试+plan 测试） | 测试钉定 |
| B1 | **跨闸门令牌重放**（边界确认） | 新闸门实例同令牌 ARM | 闸门层接受=**TCB①已声明边界**（彻底方案=SE 计数器，R2）——非静默 |

## 判定

- REJECTED=防御生效（答辩武器）；BOUNDARY=已声明边界（诚实记录）；
- ACCEPTED=**攻击得手=真缺陷，当场修+回归**。
