## 五、教训新增（㊿+42~44，入 MEMORY）

- ㊿+42：**烟测/共址测试对仪式值的破坏是系统性风险族**——pinCircuit、revRoot
  同族两案；任何「公示态」合约写面在烟测中必须保存/恢复（或跳过重设）。
- ㊿+43：**跨宿主 interop 三件套**（可执行/路径/env）须各自最小实验定谳——
  WSL interop exe ✓、wslpath ✓、WSLENV ✓ 缺一即败；探针先于编码。
- ㊿+44：FastAPI 简单类型形参= query 参数，POST body 不进——桥接 API 的控制
  面参数（pwm/hold_s/timeout_s）一律 query 传；响应平铺/data 包装双兼容取值。
