# 飞行 GCS 化改造 + 3D 实时态势 · 实施方案（2026-09-27 规划定稿，待队长拍板实施）

> 背景：队长手动验收反馈——①假链档（注入仿真样本）出现在真实应用；②飞行记录
> 设计粗糙；③2D 观感假、质疑 SITL 真实性；④拍板做 MVP 3D + 飞行记录 GCS 化
> 整体改造。本方案给出深度设计，对齐 Mission Planner / QGroundControl 的成熟
> 形态并做竞赛级合理简化。

## 〇、三条架构红线（本战役不动的东西）

1. **链语义最小化不变**：TRAIL 语句 14B 行（t,alt,lat,lon）、检查点签名、
   围栏参数、令牌五查——全部零触碰。显示增强一律走**旁路字段**（姿态/航向/
   爬升率只进 UI，不进链）——审计叙事保持干净：「链=合规证明面，UI=态势面」；
2. **闸门与安全面不变**：ARM 前置五查、一次性令牌、固件围栏参数锁定；
3. **假链退役=产品路径移除，测试替身保留在 Python 单测层**（FakeLink 类
   继续作为闸门逻辑单测的替身——替身在测试层是纪律，在产品路径是缺陷）。

## 一、现状侦察结论（2026-09-27 实测）

- **假链来源实锤**：demo_up 拉起的 **Windows 桥**（无 FZ_GCS_LINK=FakeLink）
  抢占 8100，真 SITL 桥（WSL 侧）绑不上——即㊿+40/P2-8 拓扑漂移病灶；
  本轮验收时已现场修复（杀 Windows 桥→起 WSL 桥→mode:sitl 确认）；
- **SITL 遥测面可扩展**：SITLLink 现按需 recv_match 消费 GLOBAL_POSITION_INT
  （alt/lat/lon）+STATUSTEXT（围栏）——ATTITUDE（roll/pitch/yaw）同通道
  可取（drain 模式：单次轮询双字段返回，无需第二连接）；
- **假链消费面**：FlightView（注入按钮/一键补齐/fake 分支）、server.py
  （FakeLink 默认档、sitl_sample 伪造路径、wait_gps fake 分支）、
  demo_up（拉 Windows 桥）、e2e_frontend_api（假链动线段）。

## 二、飞行记录 GCS 化 · 功能设计（对标 MP/QGC，竞赛级简化）

### 2.1 主飞行显示（PFD 简化版，自绘 canvas——零外部依赖）

| 仪表 | 内容 | 数据源 |
|---|---|---|
| **姿态球**（人工地平仪） | roll/pitch 实时，天/地双色 | ATTITUDE 旁路 |
| **高度带** | 当前高度游标 + 围栏上限红线 + 合规带阴影 + 目标高度 | 链字段+令牌 |
| **爬升率表** | 垂直速度（差分平滑） | alt 差分 |
| **航向罗盘** | yaw 罗盘刻度 | ATTITUDE.yaw |

### 2.2 飞行记录单（Flight Record——封链后自动生成）

- 起飞（ARM）时刻/封链时刻/飞行时长；峰值高度/**围栏余量**（alt_max−peak）；
- 样本数、检查点锚定次数、链头终值、事件数；
- **事件时间线**：解锁→起飞→检查点锚定×N→围栏触发（如有，红）→封链——
  每事件带时刻+链上证据（链头/tx）；状态迁移条：待飞→解锁→飞行→取证→封链；
- 本机 JSON 下载（飞行留痕；链证据已有判决件体系，不重复上链）。

### 2.3 事件时间线（飞行中实时）

前端累积+桥接既有事件面：ARM 成功/拒绝（含拒绝码）、围栏 STATUSTEXT、
检查点锚定成功、封链。时间线组件（右栏）替代静态 kv 行。

## 三、3D 实时态势 · 设计（Three.js 本地渲染，零外部依赖）

### 3.1 场景构成（FlightGlobe.vue 新组件）

| 元素 | 形态 | 说明 |
|---|---|---|
| 场地 | 网格地面+起飞坪圆盘 | 本地生成，无贴图依赖 |
| **无人机** | 自建几何四轴（中心体+四臂+四旋翼盘，盘旋转动画表转速） | 低面数、无外部资产 |
| **限高围栏** | 半透明圆柱（半径=场地、高=alt_max）+合规带高亮环 | 围栏可视化 |
| **尾迹** | 顶点动态追加折线（合规段绿/超限段红，分段材质） | 真实 SITL 轨迹 |
| 相机 | 跟随（chase）/环绕/俯视三模式切换 | 轻量自实现 |

### 3.2 渲染与数据

- npm 引入 three（bundle 增量 ~600KB gzip 后 ~150KB，可接受）；
- 采样 2Hz 轮询（既有）+ 渲染 60fps——**帧间 lerp 插值**平滑；
- 姿态四元数由 yaw/pitch/roll 合成；WebGL 生命周期管理（resize/卸载
  清理——C 席 resize 泄漏教训同款纪律）；
- **降级策略**：3D 初始化失败（WebGL 不可用）自动回退现有 2D 双图——
  2D 曲线保留不删（3D 与 2D 并存，2D 兼降级面）。

## 五、数据面扩充（桥接，链字段零变化）

- `/telemetry/sitl_sample` 响应扩展旁路字段：`yaw/pitch/roll/climb`
  （drain 模式一次轮询双取 GPOS+ATTITUDE；climb 由 alt 差分平滑）；
- **14B 链行编码不变**——旁路字段不进链、不进检查点；
- 3D/仪表消费旁路字段；TRAIL 出证装配面零改动。
