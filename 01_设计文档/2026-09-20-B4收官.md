## 二、架构与接口面

```
POST /authz/apply（匿名：会话公钥+子凭证签名+nonce+plan_hash+class_id+证明+spec+rev_root）
  → 门控序①会话钥格式②子凭证 SM2 验签（公开提交=D19 准入票据）③nonce 链查重
    ④pin 比对（本地 MANIFEST vs 链上公示）+rev_root 一致性+子凭证一次性
  → 入队 pending + 回执码（CSPRNG 128bit）
worker 轮询 → zkc verify（exit 0/2）→ 判决件归档（proofDigest/token_hash/verdict）
  → 令牌签发（engine 域 SM2）→ recordAuth+burnNonce → ECIES(会话钥) 封发回执
GET /authz/receipt/{code} → waiting / ready+token_cipher / failed
```
