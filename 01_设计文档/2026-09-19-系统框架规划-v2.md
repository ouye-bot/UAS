**Architecture:** 单一人类角色（飞手）；登记权威/政策引擎/审计台全部为自动化服务或治理面。ZK 出现在两个语句上（起飞资格证明 AUTH、轨迹合规证明 TRAIL），AUTH 语句内含 **SM3-SMT 撤销累加器非成员证明**（撤销即时生效且隐私保持）。令牌验证与高度强制分别落在地面站协议层与飞控固件围栏层，遥测出处锚定在**设备侧身份钥**。FISCO BCOS 国密联盟链承载四合约（身份/政策/授权/遥测），授权记录携带证明摘要实现**可审计签发**。

**Tech Stack:** Python 3.11 FastAPI（后端服务）、Rust zkc + vendor 钉定电路栈（证明服务）、Solidity@FISCO BCOS 2.9 国密四节点（链）、Vue3 + pymavlink 桥接（地面站）、ArduPilot SITL（演示飞行器）、三语言国密库（SM2/SM3/SM4）。

## 一、一句话定位与叙事

> **合规证明解锁起飞，飞行留痕锚定上链，追溯直达个人，身份与轨迹全程零披露。**

痛点三实锚（答辩与说明书的根，禁泛化表述）：
1. **Remote ID 广播与隐私的法定张力**——GB 42590 强制广播 ID+位置，广播面任何人可收，追踪者可定位航拍者；本系统证明可追溯性不依赖广播级身份暴露。
2. **轨迹敏感性**——航拍轨迹=家庭位置+拍摄对象+生活规律；集中式平台聚合全体飞手轨迹是真实泄露面。
3. **平台画像风险**——逐次申请交明文身份+计划，平台数据库=全体飞手移动行为画像（《个人信息保护法》最小必要原则的反面）。

竞争差异化（答辩口径）：现有体系（UOM/厂商 Geo/Remote ID）把可追溯建立在"人人可见"上；学术隐私 UTM 有提案无可运行系统；国密 ZK 电路栈此前不存在——本作品三者同时成立，且合规结论**直达物理硬件**（固件围栏）。

**法律定性（D15）**：本系统令牌为**治理层门禁与合规基础设施凭证，不是行政许可**。主场景是法规无需逐次审批的适飞空域；价值主张=自愿采用的合规与隐私能力（厂商预装/机队管理/保险激励），远期与 UOM 对接。说明书与答辩禁用"替代审批/行政许可"表述。

**核心循环**：注册签发（加盐承诺凭证）→ 申请子凭证 + 取撤销见证 → 匿名申请（AUTH 证明+子凭证签名+会话公钥）→ 门控与验证（廉价检查→ZK 验证）→ 签令牌+链上注册（proof_digest+nonce 烧毁）→ 加密返回+回执码 → 验签解锁（地面站+固件围栏）→ 飞行留痕（设备钥签名遥测哈希链+检查点锚定）→ 超限自动取证（固件拦截事件上链）→ 落地合规证明（TRAIL）→ 令状追溯（RA 协作解锁，令状自留痕）。

**匿名性边界（写进说明书的诚实口径）**：授权服务与链上公开面零身份；**平台后端的账户库与 RA 的实名映射库是关联点**——实名映射密文落库、令状+RA 双控解密、解锁行为上链。不可链接（跨申请）经一次性子凭证达成；对平台自身隐藏需盲签，明确不做（登记权威协作追溯是设计特性）。

## 五、ZK 语句定义（本系统仅此两条）

### 5.1 AUTH——起飞资格证明（起飞前，主循环内）

**语义**：证明者持有登记权威对承诺 C 签发的有效子凭证，承诺原像满足：实名身份（隐藏）、操作资质等级 ≥ 该机型类要求、无人机序列号哈希=申请序列号哈希、凭证未过期、**其主凭证句柄不在当前纪元撤销累加器中**，且本次申请绑定（计划哈希，nonce，政策版本）。

**报文 M_A（165B）**：

```
M_A = Z_A(32) ‖ x(id′_u·G)(32) ‖ C(32) ‖ pk′_u.x(32) ‖ pk′_u.y(32) ‖ exp_u BE(4) ‖ par(1)
C   = SM3( salt(16) ‖ cert_level BE(4) ‖ id_number(18) ‖ sn_h(16) )  # 54B，SM3 单块（B3-d8：cert 居词 4=范围门读数源零接线）
sn_h = SM3( drone_serial )[0..16]
```

**公开输入（含公开提交）**：`policy_version(4B)、class_id(1B)、alt_max(u16)、required_level(1B)、plan_hash(32B)、nonce(16B)、t_epoch(4B)、RA 公钥引用、电路 pin 指纹、**子凭证签名 (r_s,s_s)（公开提交，兼作受理门控票据——一次性数据，公开不产生跨次关联）**、**撤销纪元根 rev_root(32B)（取自 IdentityRegistry 链上公示的当前纪元）**`。**sn_h 不在公开面**（B3 实现定谳：sn_h 已收进承诺 C 原像——设备级跨次关联点消除，见 v2.2 变更记录）。

**私密见证**：`salt、id_number、cert_level、sn（sn_h=SM3(sn)[0..16] 进 C——序列号全程不出设备）、sk′_u、id′_u、exp_u、**SMT 非成员认证路径（32 × 32B，叶→根序）**`。

**电路约束构成（B3 实装）**：M_A 重建+SM3 三块（SM3_LUT 查表化，部署默认）→ 词序折叠 e → SM2 验签体（E8-E10：[sk′]G 循环/双承诺/聚合公钥 apk=pk′+pk_RA）；C 原像绑定（54B 单块查表 SM3）；`cert_level ≥ required_level` 范围门（承诺消息词 4=读数源，δ 位+recomb 消费式钉）；`exp_u ≥ t_epoch` 有效期谓词（S6）；绑定方程（plan_hash/nonce/policy_version 服务层复合折算进 ctx_tag/pred_id 二实例钉——B3-d10，信任假设 T6 显式登记）；**撤销累加器非成员证明（D14/B3b：深度 32 SMT，键=pk′.x，EMPTY 叶起链+路径 mux+根折叠实例钉——见 §5.1a）**。sn_h 电路内等值钉归 B3b 分账（出厂=host+链上 sn_hash 绑定）。

**机型类公开的口径**：机型类=公开输入（Remote ID 本就广播）；序列号、身份、资质等级=隐藏。**撤销的隐私性**：路径为私密见证，公开面只见纪元根——被吊销者下一次申请即被电路**数学拒绝**，撤销即时生效且不暴露"谁是撤销者"以外的任何信息。

**规模与性能 [实测 2026-09-20 B4 交付口径，含 SMT/class 钉]**：**104,287 约束 / polys 13,513 / lookups 24 / 实例 24**；proof=435,937,488B；**prove 40.8s / verify 6.1s @服务器 12C/46Gi（≤60s 预算硬门达标）**；本机（R1 优化后）prove 118.6s/内存峰值 14.3GB；pin 指纹随 vendor 换代（现行 SM3(3d1b091|394dd3e7…)）fail-closed 生效。

### 5.2 TRAIL——轨迹合规证明（落地后，离线）

**语义（诚实收窄）**：证明者知道一段**设备签名且已锚定**的遥测样本序列 (h_i, t_i)，其 SM3 哈希链头=飞行中锚定的公开链头，每个样本高度 ≤ 授权上限，时间戳按声明采样率严格连续，K 个**设备钥**检查点签名有效——结论是"**设备签名且未被篡改的记录显示全程合规**"，而非"飞行客观合规"（后者依赖设备 TCB，见 §九）。

**公开实例**：`chain_head(32B)、alt_max(u16)、t_start/t_end(4B×2)、sample_rate、设备公钥引用`。
**私密见证**：`n 组 (h_i,t_i)、K 个检查点签名`。

**电路约束构成（B6 实装）**：SM3 哈希链展开（消息级链：每块 fresh IV+块 i+1 消息词 0..7 复制环绑块 i 摘要+genesis 常量钉，查表体）；n 个范围门 `h_i ≤ alt_max`（δ′16 位分解全局一份）；时间戳等值门（Δ=500）；链头==锚定链头实例钉。**检查点设备验签在装配/锚定面 fail-closed 执行**（B6-d8'：msg/sig/公钥皆链上公开数据，电路内重验=零密码学收益；坏签名/换头=装配拒绝）——**检查点报文绑定固件围栏状态（使能位+上限值）**——与固件拦截事件交叉印证。

**参数默认值**：采样率 2Hz；n=128（64 秒段，B6-d1 定档——列爆炸实测定谳）；更长飞行分段证明（本栈无递归，逐段展开=唯一路径，诚实边界）；检查点间隔 60s（服务面 1..=4 个/段）。**安全时间=设备 TCB 声明**；违规事实的时间戳以**固件事件为权威源**（非用户软件产生）。
**规模与性能 [实测 2026-09-21，B6 收官]**：**532 约束 / polys 4,481 / lookups 1,024 / 实例 1**；本机 prove 297.0s（release 直跑）；**服务器 12C/46Gi prove 14.77s·verify 0.20s·total 33.2s（interleave 构型，proof 16,249,632B）**；负例（超限/时间空隙/换链头/t_start/坏设备签名）全部数学拒绝。

### 5.3 明确不用 ZK 的位置

令牌验证（签名校验，毫秒级）；遥测锚定（哈希链）；追溯（承诺打开+令状）；政策表查询（公开数据）。ZK 只站刀刃。

## 六、联盟链设计（FISCO BCOS 2.9 国密四节点，四合约）

**链的三条存在理由**：①授权记录不由单一运营方掌控；②遥测留痕多方锚定防单方抵赖；③追溯行为本身可审计。

### 6.1 IdentityRegistry（身份注册表）
```solidity
function registerCommitment(bytes32 masterCredHash, uint8 credKind) external onlyRA;
function setStatus(bytes32 masterCredHash, uint8 status) external onlyRA;
function setRevocationRoot(uint64 epoch, bytes32 revRoot) external onlyRA;  // 撤销累加器纪元根
function logWarrant(bytes32 warrantHash, bytes32 scopeHash) external onlyAuditor;
function isRevoked(bytes32 masterCredHash) external view returns (bool);
```
- 主凭证哈希+状态存本合约（D18）；**撤销=RA 更新累加器树+公示新纪元根——被吊销者下一次申请即被 AUTH 电路数学拒绝，即时生效**。链上只有承诺哈希与状态；实名映射在 RA 库密文落库，令状+RA 双控解锁。

### 6.2 PolicyRegistry（政策注册表）
```solidity
function publishPolicy(string calldata version, bytes32 paramsHash) external onlyAdmin;
function pinCircuit(bytes32 pinFingerprint) external onlyAdmin;
function setClassRule(uint8 classId, uint16 altMaxM, uint8 requiredLevel) external onlyAdmin;
function getClassRule(uint8 classId) external view returns (uint16, uint8);
```
- 政策表种子=《无人驾驶航空器飞行管理暂行条例》公开数值，实施时从条例原文逐条摘录并注明出处（禁手抄记忆）。`pinCircuit` 承接 A8：授权服务启动 fail-closed 比对。

### 6.3 FlightAuthRegistry（授权注册表）
```solidity
function recordAuth(bytes32 tokenHash, bytes16 nonce,
                    uint8 classId, uint16 altMaxM, uint40 tStart, uint40 tEnd,
                    bytes32 subCredHash, bytes32 proofDigest) external onlyEngine
                    returns (uint256 authId);   // v2.2（B3b-d6）：删 snHash——设备绑定由证明承担，链上零设备信息
function burnNonce(bytes16 nonce) external onlyEngine;
function revokeAuth(uint256 authId, uint8 reason) external onlyEngine;
function nonceUsed(bytes16 nonce) external view returns (bool);
mapping(bytes32 => bool) public usedSubCreds;   // v2.2（B1-d2）：子凭证唯一性链级强制——同 subCredHash 二次授权 revert
```
- **`subCredHash`=子凭证哈希（D18 定谳）**：每申请全新→同一飞手的链上授权记录逐次不可关联。
- **`proofDigest`=已验 ZK 证明的 SM3 摘要（D17）**：判决件按 authId 归档可下载，任何第三方可对链上摘要事后独立复验——把"政策钥持有者诚实"从纯信任升级为可审计信任。
- `authId` 是全系统贯穿键；链上无身份列。

### 6.4 TelemetryAnchor（遥测锚定）
```solidity
function anchorCheckpoint(uint256 authId, uint32 seq, bytes32 chainHead,  // 设备签名公开=设备层可链接（防伪来源）；身份层不可链接不变（D18）
                          bytes calldata deviceSig) external;          // 每60s，设备钥签名
function recordEvent(uint256 authId, uint8 eventType, bytes32 eventHash) external;
function verifyHead(uint256 authId, bytes32 chainHead) external view returns (bool);
```
- `eventType`：1=固件围栏触发 2=地面站监测超限 3=通信中断 4=迫降记录。第三方离线验真：重算链哈希→重算检查点→链上回读（exit 0/2）。

**链不做的事**：验证 ZK 证明（四条死因：资源量级差 3~6 个数量级/EVM 平台硬限制/共识层架构负收益/验证器重实现风险反向——详见三视角评审 §一）；存轨迹明文；当用户侧共识节点（用户=轻客户端签名交易）。

## 七、系统服务与模块设计

### 7.1 登记权威（RA，自动 CA）
- 注册仪式：实名提交→salt（CSPRNG）→C=SM3(salt‖cert BE4‖id‖sn_h)（54B 单块）→RA 主钥签 M_A（裸摘要通道+电路词序口径，跨语言黄金向量钉定）→**双通道回传（B2 定谳）**：ECIES(pk_user) 原像密文=用户自持；**RA 域钥 wrap 的实名映射密文落库=令状通道（B4/B7 补端点——队友六问 A3）**→masterCredHash 上链。
- 子凭证仪式：fresh id′/salt′/pk′（sk′ 端侧生成）→签 M_A′→短效 exp′（默认 24h，≤ 主凭证）。**配额限制（单主凭证未消费子凭证上限）+批量预签缓解时序画像（D19/P2-4）**。
- **撤销累加器（D14）**：维护以主凭证句柄为键的 SM3-SMT；吊销→更新叶→`setRevocationRoot` 公示新纪元根；**撤销见证分发**（匿名获取；公开镜像+RA 双源，缺失=该纪元无法申请 fail-closed；获取时点可见性并入已声明 RA 时序侧信道）。
- 令状协作：验证令状（链上 WarrantLog 在案）→解密实名映射→返回解锁结果→解锁记录上链。

### 7.2 授权服务（政策引擎）
- **受理门控序（D19，廉价先于昂贵）**：①会话公钥格式→②子凭证签名 SM2 验签（公开提交，毫秒级）→③nonce 链上查重→④电路 pin 比对→通过才进 ZK 验证队列。**电路内仍全量验证**：宿主检查=DoS 门控，电路=密码学权威，两层角色分离并声明。
- **匿名返回（D19/P0-3）**：提交携一次性会话公钥→令牌+受理回执以会话钥加密返回；128 位随机回执码支持异步/跨设备查询；回执与会话表零身份列（模型级测试断言）。
- 验证通过→机型类查政策表→签令牌→`recordAuth(subCredHash, proofDigest)`→nonce 烧毁。**撤销校验**：确认公开实例 rev_root=链上当前纪元根（电路内非成员证明已数学强制）。
- **可审计签发（D17）**：判决件三件套按 authId 归档可下载；第三方以公开 zkc verify 对链上 proofDigest 事后复验。
- 令牌格式（v2.2，队友六问 A2）：`{authId, plan_hash, sn_hash, alt_max, t_start, t_end, nonce, policy_version, Sig_engine}`——**plan_hash 必入令牌**（申请意图指纹：防重放/防挪用；计划符合性核查不在证明语义内）；链上 recordAuth 的 tokenHash=SM3(完整令牌) 隐含绑定；令牌经会话钥加密返回（非公开面）。政策钥域分隔派生自 KMS（B2 定谳双钥分离：凭证签名钥≠链交易钥）。

### 7.3 地面站（gcs/bridge + web）
- **模拟设备钥（D16/TCB）**：桥接进程持有设备侧身份钥（真机=伴飞计算机+SE/TCM 芯片），遥测哈希链头与检查点由设备钥签名，检查点报文绑定围栏状态。
- 验签 arm 闸门：验令牌→设 `FENCE_ENABLE/FENCE_ALT_MAX`→ARM；失败拒绝并留本地审计行。
- 遥测记录器：2Hz 采样→SM3 哈希链→每 60s 设备钥签名链头→授权服务转锚定→围栏触发事件捕获→recordEvent。
- TRAIL 任务：落地后组装见证（含设备签名检查点）→提交授权服务证明队列→判决件归档+链上锚结论。
- **回执码本地保存**（P0-3）；**预授权窗**（出发前申请，令牌窗覆盖作业时段——无网现场不可申请为诚实声明，P2-3）。
- Web UI 单角色五屏：申请（进度可见）/令牌与飞行/留痕与合规证明/回执查询/我的记录。**负例按钮一等公民**。

### 7.4 审计台（单屏治理面）
- 三步：创建令状（案号+scope+法律依据哈希）→上链 WarrantLog→RA 协作解锁→展示实名关联与全部留痕。审计员密钥认证；令状不可撤销只能追加更正记录。
