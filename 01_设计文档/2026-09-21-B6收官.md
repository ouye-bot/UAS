## 一、语句级安全论证（硬验收门：R_TRAIL 归约）

### 1.1 R_TRAIL 语句（框架 §5.2/A5 收窄语义）

```
公开输入：chain_head(32B，实例 0=词序折叠 fold_words_be——锚定链头)
电路常量：alt_max、t_start、n=128、500ms 采样周期、genesis 常量词
私密见证：n 组 (t_i, alt_i, lat_i, lon_i)、δ′ 位分解、影子格
关系：
  h_0 == SM3(b"FZ-TEL-GENESIS")（genesis 常量词钉块 0 消息词 0..7——复制环强制）
  ∀i∈[0,n)：block_i = pad64(h_i ‖ t_i‖alt_i‖lat_i‖lon_i)   （46B 消息恰满单块）
             h_{i+1} == SM3_compress(IV_std, block_i)        （每块 fresh IV——查表体）
             块 i+1 消息词 0..7 == 块 i 摘要词               （复制环=链 soundness）
  ∀i：δ′_i = alt_max − alt_i 的 16 位分解（bool 位）∧ Σ2^k δ′_k + alt_i == alt_max
      （域内等式+bool ⟹ δ′∈[0,2^16) 整数 ⟹ alt_i ≤ alt_max）
  ∀i∈[0,n)：t_{i+1} − t_i == 500                              （等值钉，2Hz 严格连续）
  t_0 == t_start                                              （起始钉）
  fold(链头) == chain_head 实例                                （锚定钉）
检查点面（装配/锚定面，非电路内）：
  ∀cp∈checkpoints：Verify_SM2_bare(P_dev, SM3(FZ-CHK|auth_id‖seq‖chain_head‖fence_state), cp.sig)
  （msg/sig/公钥皆链上公开数据——B6-d7/d8' 定谳，见 §四）
```

### 1.2 健全性归约

| 构件 | 电路/装配面强制 | 归约 |
|---|---|---|
| 链完整性 | 消息级复制环（块 i+1 词 0..7←块 i 摘要；genesis 常量词） | 改任何中间样本 ⟹ 链头变 ⟹ 锚定钉拒（SM3 抗碰撞） |
| 单块压缩 | 查表 SM3 体（4 约束/块+8 查表）+msg recomp | 假块 ⟹ 违约（B3 族已证） |
| genesis 钉 | 常量词（CONST 通道 pconst 同步，const_c 全点） | 换起点结构性不可证明（环强制）；终局兜底=链头钉（换 genesis 必换末头） |
| 高度范围门 | δ′ 16 位 bool+recomb（z prep 门控@样本行） | alt>max ⟹ δ′ 为 2^64 域大数 ⟹ 低 16 位组装+alt≠alt_max ⟹ 违约（负例①恰 1 条） |
| 时间连续门 | 等值钉 Δ=500（z prep 门控@配对行） | 空隙/稀疏采样 ⟹ 违约（负例②恰 2 条=受影响配对） |
| t_start 钉 | 等值钉（z prep 门控） | 声明起始≠记录首样本 ⟹ 违约（负例④） |
| 锚定钉 | fold==实例（f_pow2 权威派生系数） | 任何见证链 ⟹ 末头必须==链上公示 chain_head |
| 检查点验签 | **装配面 fail-closed**（verify_checkpoint_sig，跨语言 Py 签↔Rust 验） | 坏签名/换头报文/错钥 ⟹ 装配拒绝 RC=2（B6 验收门④的兑现面） |

**A5 语义精确性**：证明结论=「已锚定记录中的**全部高度样本**满足上限+时间严格连续」，
非「全程未超限」（采样间隔瞬超=信息论边界，连续强制由固件围栏层承担——P0-1/六问 A5）。
轨迹明细（lat/lon/中间头）零披露——见证不出电路。

## 三、B6-T2 卡点根因链（旧证据链修正+四道根治守卫）

交接锚的「Query 引用 vs witness 实格错位」假说**不成立**——重跑 FZ_TRAIL_DBG=1 分解器
显示约束正确读到 p=605(local 580)=w0 影子格，`Σ影子≠inst0` 才是实锤。真根因与修复：

| # | 根因 | 实锤 | 修复 |
|---|---|---|---|
| 1 | **chain_circuit 的 IV 链传语义对 TRAIL 是错函数**（v=dg 逐块下传=SMT 双块形态；TRAIL=每块 fresh IV、链在消息） | 电路 digest[0]=0x57626912 ≠ Python 独立重算链头 w0=0x7a69cd3c | 新增 `trail_chain_circuit`：prev=None 常量 IV+`compress_entry_binds` 消息级绑定（块 0 词 0..7←genesis 常量词；块 i+1←块 i 摘要） |
| 2 | head 桥 perm 条目 proto 号漏规范化 | digest_cells.limb.col 是 proto 24 基，push 未 +1 → 环错指 prep 24 段 | `(limb.col+1+NZ, row)`（桥接回读守卫当场验证） |
| 3 | num_witness_polys 未随 104 列追加同步 | 后端 prover 按其断言列数 | `= vec![witness.len()]` |
| 4 | **z 选择器 witness 化=健全性漏洞**（自查发现：恶意证明者置 z≡0 ⟹ 全部门空转） | 设计审查（AUTH 的 sel=prep 先例对照） | **z 迁 preprocess 常量列**（B6-d9）——编号双基底拆分（prep+1/advice+1+NZ） |
| 5 | 范围门 per-sample 复制冗余 | over-limit 负例 16 条同点违约（同一表达式 16 份） | 全局一份：16 bool+1 recomb（约束 4n+17n+3→4n+20） |
