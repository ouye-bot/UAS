## 二、核心产出

- **credential.py**：M_A 模块（fork 旧 pred_credential 同构改造）——C=SM3(salt16‖id18‖cert1‖sn_h16)=51B 单块加盐承诺（D10）；sn_h=SM3(serial)[:16]；par=0x02|lsb；词序小端折叠 e（SP-19 定谳口径）
- **smt.py**：SM3-SMT 深度 64（DEFAULT 哈希链+成员叶域分隔标签+LSB→MSB 兄弟序）；非成员证明 64×32B；100 组随机差分全过（成员必拒/换根必拒/集合序无关）
- **service.py**：三仪式（register/issue_sub_credential/revoke）+快照；配额 20/24h TTL；纪元权威=链上（`chain_rev_epoch` 注入——本地 epoch 漂移 revert 实锤后定谳修复）
- **router.py**：四端点+healthz（负例 HTTP 语义 403/409/429/404）；fake 链锚注入测试
- **DB**：alembic 0001 四表（users/credentials/sub_credentials/revocations）；id_number 零明文（ECIES 密文+承诺）
- **KMS 简版**：凭证签名钥（KMS 域）与链交易钥（B1 域）**分离**——链钥轮换不影响凭证验证公钥
- 黄金向量（B3 消费）；性能档案 B2 行（register 37.3ms/子凭证 21.6ms [实测]）

## 四、执行期问题与根因

| 问题 | 根因 | 修复 |
|---|---|---|
| SMT 见证方向序错（首版非成员验证失败） | 叶层兄弟=完整位置 LSB 翻转，逐层向 MSB；方向位=本层最低位（非路径最高位） | 重写 witness/verify+100 组随机差分钉定 |
| service fixture AttributeError | RaDeps.anchor 是 ChainAnchor(call=…) 而非裸 callable | fixture 包装修正 |
| 真链 setRevocationRoot revert 0x16 | 纪元权威分裂（本地 epoch vs 链上已被 B1 烟测推进） | B2-d10 链上纪元注入 |
| Windows 临时库 PermissionError | SQLAlchemy 连接池持文件锁+未 commit 事务 | commit+dispose+mkdtemp best-effort |
| 锚参数 hex 字符串 vs binding 需 bytes | service 传 "0x…" | 锚内 _b32 转换 |

**教训（入 MEMORY）**：① 双钥分离架构（凭证钥/链钥）在权限校验 FAIL 时第一时间定谳——链上权限地址==交易钥≠凭证钥；② 纪元等链上全局状态必须单权威（链），本地缓存仅显示用；③ SMT 方向序用随机差分钉死（人脑推方向序易反）。
