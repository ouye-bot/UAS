03第三方复验（两步）

材料：任一授权的「留痕与 TRAIL」页下载的复验五件 （proof.bin / verifier_param.bin / instances.json / verdict.json / expected.json）。

# ① 校验工具完整性
sha256sum -c SHA256SUMS.txt
# ② 独立验证（Linux x86-64；无需本系统任何服务在线）
export FZ_TRAIL_CANONICAL_SPEC=trail_canonical_spec.json   # 留痕页同处下载
export FZ_ZK_ALLOW_TRAIL=1
chmod +x zkc-linux-amd64
./zkc-linux-amd64 verify-instances \
  --instances instances.json --proof proof.bin \
  --vp verifier_param.bin --expected expected.json
# 期望输出：zkc verify-instances: OK（篡改链头 → exit 2 拒绝）

wasm 档：wasmtime run --dir .::/ --env …（同参）zkc.wasm verify-instances … ——完整配方见作品文档《性能档案》WASM 节。

04边界声明

① 本分发只含验证器（verify-instances）：验证不消费秘密见证与 vendor 源树，单二进制即可复验； 证明器（prove）不在分发面——证明在飞手本机桥接内完成，见证不出设备（隐私架构事实）。
② AUTH 证明的复验同口径（FZ_ZKSVC_DIR 指向完整工作区时 prove 面可用；纯验证不依赖）。
③ 分发产物与链上公示指纹由构建方一致性背书；第三方可用 zksvc-build-manifest.json 交叉核对钉定源（git archive 可复现同一快照）。
